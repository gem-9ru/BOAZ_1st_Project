# build/ — 파이프라인 중간 산출물

`data/` 만 있으면 아래 세 명령으로 전부 재생성됩니다.

```bash
python3 src/pipeline/normalize.py      # -> 공고_정규화.csv   227,215행  82MB
python3 src/pipeline/dedup.py          # -> 공고_통합.csv     161,355건  65MB
                                       # -> 중복매핑.csv      227,215행  42MB
                                       # -> 검수후보.csv      (0행)
python3 src/pipeline/extract_busan.py  # -> ../부산/
```

| 파일 | 무엇 |
|---|---|
| `공고_정규화.csv` | 스키마 통일·알바 제외·마감 필터·직무 보강까지 끝낸 **행 단위** 데이터. 아직 중복이 있음 |
| `공고_통합.csv` | 중복을 병합한 **공고 단위** 데이터 (전국) |
| `중복매핑.csv` | 원본 행 → `통합키` 대응표 + 병합근거. 어떤 행이 왜 묶였는지 추적용 |
| `검수후보.csv` | 유사도가 애매해 사람이 봐야 하는 쌍. 현재 0행 |

**용량이 커서 git 에 올리지 않습니다**(`.gitignore`). 위 명령으로 만드세요.
