## 직무 출처 우선순위

`직무` 칸은 아래 순서로 만듭니다. 1·2 는 사이트가 분류한 값이라 그대로 신뢰하고,
3~6 은 자유 서술이라 직무 어휘 사전(약 350개)으로 걸러서 씁니다.

```
1. 직종        사이트가 붙인 표준 직업분류명
2. 직무키워드   사이트가 붙인 직무 코드
3. 모집분야     자리 이름
4. 원본 직무 칸
5. 공고제목
6. 담당업무 첫 문장
```

제목에서만 뽑던 이전 방식은 "2026년 신입사원 공개채용" 같은 공고에서 아무것도 못 건졌습니다.

## 채용인원을 세 칸으로 나눈 이유

표기가 사이트마다 다릅니다.

```
잡코리아  "1 명" / "○ 명"(미정)      부산일자리정보망  "1" / "0"
사람인    "(3명)" — 정형 템플릿만     커리어           "0명"
```

`0` 과 `○` 는 "뽑긴 뽑는데 몇 명인지 안 밝힘" 이라 0명이 아닙니다.
미정을 0으로 잡으면 수요가 과소, 1로 잡으면 과대가 됩니다.
그래서 원문·숫자·구분을 모두 남겨 분석 단계에서 고르게 했습니다.

| 출처 | 명시 | 미정 |
|---|---:|---:|
| 부산일자리정보망 | 99% | 1% |
| 잡코리아 | 48% | 50% (`○ 명`) |
| 사람인 | 부분 | 자유 서술 공고엔 없음 |
