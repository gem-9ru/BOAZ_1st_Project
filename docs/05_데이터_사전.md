# 데이터 사전

## `data/{사이트}.csv` — 사이트별 원본

수집 직후. 사이트 값을 최대한 그대로 둡니다.

| 컬럼 | 설명 |
|---|---|
| `사이트` | 수집처 |
| `회사명` | 사이트 표기 그대로 |
| `공고제목` | |
| `직무` | 사이트가 제공하는 직무·직군. **사이트마다 의미가 다릅니다** |
| `경력` | 원문 (예: "경력 3년 이상", "신입/경력") |
| `고용형태` | 원문 |
| `지역` | 원문 (예: "부산 해운대구", "부산 부산전체,경남 김해시") |
| `기술스택` | IT 사이트만 채워집니다 |
| `마감일` | `YYYY-MM-DD` 또는 "상시채용"·"채용시 마감" |
| `공고URL` | |
| `외부원본ID` | 재노출 사이트가 밝힌 원출처 (예: `saramin:817303`) |
| `수집시각` | |

## `build/공고_정규화.csv` — 정규화 결과 (200,502행)

행 = 원본 공고 1건. 아직 중복이 남아 있습니다.

| 컬럼 | 설명 |
|---|---|
| `통합키` | 중복 병합 후 부여되는 그룹 ID |
| `사이트` `원본공고ID` | 출처 |
| `회사명` | 원문 |
| `회사키` | 법인격·공백 제거한 정규화 회사명. 중복 판정용 |
| `공고제목` | |
| `직무` | 정규화 + 제목 추출 보강본. 쉼표로 구분된 토큰 |
| `경력구분` | `신입` / `경력` / `신입·경력` / `무관` |
| `최소연차` | 정수. 없으면 빈 값 |
| `고용형태` | 원문 |
| `고용형태표준` | `정규직` / `계약직` / `인턴` / `파견` / `프리랜서` |
| `알바여부` | 알바 판정 결과 (Y 인 행은 이미 제외됨) |
| `시도` | `부산` / `서울` 등 광역 단위 |
| `시군구` | `해운대구` 등 |
| `지역원문` | 분해 전 원본 문자열. 다지역 공고 판별에 씀 |
| `기술스택` | |
| `마감일` | `YYYY-MM-DD` |
| `마감구분` | `날짜` / `상시` / `채용시` |
| `공고URL` `외부원본ID` `수집시각` | |

| `부산판정근거` | 뜻 |
|---|---|
