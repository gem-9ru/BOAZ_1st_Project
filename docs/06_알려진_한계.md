### 직무 칸이 메뉴 이름 — 해결

부산일자리정보망 직무 칸은 `기업채용`/`공공채용`/`해외채용` 세 값뿐이었습니다.
100% 채워져 있지만 정보량은 0이었고, 부산 데이터의 78%가 여기서 왔습니다.

목록만 받고 상세를 안 받은 게 원인이었습니다. 상세에는 `직무내용`·`직종`·`업종`·
`고용형태`·`모집인원`이 다 있습니다. `src/busanjob_detail.py` 로 받습니다.

### 학력 요건 없음 — 해결

대졸 수요를 세려면 필수인데 전혀 없었습니다.
잡코리아·사람인·커리어 목록에 학력 칸이 있어 확보했습니다 (채움률 99~100%).

### 학력·급여가 CSV 에 안 담김 — 해결

`Site.save()` 가 고정 12칸만 쓰고 나머지를 조용히 버렸습니다.
로그에는 "학력 8,639건" 으로 찍히는데 파일에는 컬럼 자체가 없었습니다.
`site.extra_cols` 를 추가했습니다.

## 남아 있는 것

### 1. 채용인원 미정 — 잡코리아 50%

잡코리아 공고의 절반이 `○ 명` 입니다. 기업이 인원을 입력하지 않은 것이라
상세 어디에도 없습니다. 복구 불가.

`채용인원구분` 컬럼으로 `명시`/`미정`/`없음` 을 구분해 뒀으니
집계 시 미정을 어떻게 볼지 분석 단계에서 정하면 됩니다.

| 출처 | 명시 | 미정 |
|---|---:|---:|
| 부산일자리정보망 | 99% | 1% |
| 잡코리아 | 48% | 50% |
| 사람인 | 부분 | 자유 서술 공고엔 없음 |

### 2. 담당업무 — 사이트마다 확보율이 크게 다르다

**"구체적으로 어떤 일을 하는지"** 가 이 데이터셋에서 가장 중요한 정보인데,
사이트마다 원본이 이걸 갖고 있는 정도가 다르다.

| 사이트 | 상세 | 담당업무 | 원인 |
|---|---:|---:|---|
| 사람인 | 5,670 | **91%** | 상세요강이 정형 템플릿 |
| 리멤버·원티드·점핏·미디어잡 | 193 | **100%** | API 가 `main_tasks` 를 준다 |
| 잡코리아 | 8,200 | 수집 중 | **상세요강이 별도 iframe** (아래) |
| 부산일자리정보망 | 25,326 | **16%** | 워크넷 등록분만 원본에 `직무내용` 이 있다 |
| 커리어 | 5,070 | **0%** | 부산분 전량이 워크넷 연계, 상세가 빈 껍데기 |

**잡코리아 — 상세요강이 메인 페이지에 없다**

```
/Recruit/GI_Read/{gno}                     ← '상세요강' 제목만 있고 내용은 비어 있음
/Recruit/GI_Read_Comt_Ifrm?Gno={gno}       ← 담당업무 본문은 여기
```

메인만 파싱해서 담당업무가 0% 였다. iframe 을 한 번 더 받도록 고쳤다.
공고당 2요청이 되지만 이 필드가 그만한 값어치가 있다.
이미지로만 된 공고는 여전히 빈칸이다(표본 5건 중 1건).

**부산일자리정보망 — 원출처별로 갈린다**

```
work24.go.kr(워크넷)   3,964 / 3,965   100%
saramin.co.kr             39 / 15,519    0.3%
jobkorea.co.kr             0 /  5,751    0%
```

사람인·잡코리아 재노출분은 부산일자리정보망이 상세를 받아오지 않는다.
잡코리아분 5,751건은 `GI_No` 교차 연결로 잡코리아 상세에서 메운다.

**커리어 — 방법이 없다**

부산분 표본 25건이 전부 워크넷 연계였고, 상세페이지에 담당업무·관련키워드·업종이
전혀 없다. 워크넷 ID 도 노출하지 않아 원본 추적도 안 된다.
목록의 해시태그 24%(1,455건)가 이 사이트에서 얻을 수 있는 직무 정보의 전부다.

**워크넷 직접 수집은 막혀 있다**

커리어·잡코리아 부산의 상당수가 워크넷(고용24) 연계라 원본을 직접 받으면
한 번에 해결되지만, `work.go.kr/robots.txt` 가 채용정보 경로를 전면 차단한다.

```
User-Agent: *
Disallow: /empInfo/          ← 채용공고 목록·상세가 전부 이 아래
```

부산 8,073건이 있는 것을 확인했으나 수집하지 않는다.
`work24.go.kr`(신규 도메인)은 `/wk/` 를 허용하지만 목록 페이지가 렌더링되지 않아
진입점이 없다.

### 3. 직무가 표준 분류가 아니다

사이트마다 자체 태그 체계라 그대로는 집계가 안 됩니다.

```
잡코리아  "국제금융, 금융, 은행, 문서관리, 전산입력, 서무, 행정, …"
사람인    "SNS마케팅, 광고마케팅, 바이럴마케팅, 콘텐츠마케팅"
커리어    "기구설계, 자동차부품개발, CATIA"
부산잡    "제도사"  ← 이것만 표준 직업분류(KECO)
```

**미착수.** 표준 체계로 재분류해야 직무별 수요 집계와 전공 연결이 가능합니다.
후보는 KECO(한국고용직업분류)와 잡코리아 21대분류입니다.
수집이 끝난 뒤 실제 태그 분포를 보고 정하기로 했습니다.

### 4. 커리어 직무 태그 29%

커리어는 상세모집요강이 **base64 PNG 이미지**인 공고가 많아 본문에서 직무를 못 뽑습니다.
목록의 해시태그가 있는 공고만 직무가 채워집니다 (5,070건 중 1,455건).
관련 키워드(`a.lobs`) 블록도 소수 공고에만 있습니다.

### 5. 자소설닷컴 지역 필드 없음

원본에 근무지역이 아예 없습니다. 목록 API·상세페이지·JSON-LD 를 다 확인했고
`jobLocation` 이 빈 배열입니다. 제목에 부산이 있는 31건만 판정됩니다.

대기업 공채 위주라 대졸 수요 분석에는 아쉬운 결손입니다.
다만 마감 필터 후 315건만 남아 규모는 작습니다.

### 6. 사람인 상세 — IP 차단으로 중단

사람인 상세를 4워커 3req/s 로 6,400건 받다가 **IP 레벨 차단**을 당했습니다.
HTTP 오류가 아니라 TCP connect 자체가 안 됩니다(`연결 0.000000s`, 타임아웃).
경고 없이 방화벽 단에서 끊겼습니다. 제가 너무 빠르게 요청한 결과입니다.

```
확보    5,670건 (체크포인트 보존)
미확보  8,276건
```

**목록 13,946건은 온전합니다.** 회사명·공고제목·직무태그·학력·경력·고용형태·지역·마감일이
모두 있고 직무 태그 채움률은 100% 입니다. 막힌 건 상세의 서술형 필드뿐입니다.

**부산일자리정보망 경유로 일부 보완했습니다.** 부산잡이 사람인 공고를 재노출하면서
상세를 함께 갖고 있고, 거기에 원출처 `rec_idx` 가 적혀 있습니다.

```
부산잡 상세가 가진 사람인 원출처   12,820건
미확보 8,276건 중 메운 것          3,761건
어느 쪽으로도 상세 없음            4,515건
```

단 사람인 원출처 공고에는 `직무내용` 이 없습니다.
얻는 것은 **고용형태·근무지역·경력학력조건·임금조건·모집인원·업종** 입니다.
`pipeline/detail_join.py` 의 원출처 교차 연결이 이 일을 합니다.

**교훈** — 실패가 조용했습니다. 워커 4개가 전부 연결 대기에 물려 6분간 아무것도 못 하는데
프로세스는 살아 있고 로그도 마지막 줄에서 멈춰만 있어 진행 중처럼 보였습니다.
`common.fetch_many` 에 **연속 실패 60건이면 중단**하는 차단 감지를 넣었습니다.

### 7. 잡부산시대 — 통합 데이터셋에서 제외

상세페이지 하단에 이런 고지가 있습니다.

> "누구든 본 정보를 (주)부산시대신문사의 **동의없이 재배포할 수 없으며**
>  본 정보를 출력 및 복사하더라도 **구인구직 활용외 다른 용도로 사용할 수 없습니다.**"

`robots.txt` 는 `Allow: /` 라 1층은 통과했고 목록 페이지에도 이 문구가 없습니다.
**상세페이지에서만** 걸렸습니다.

수집분 170건은 `data/잡부산시대.csv` 로 **로컬에만** 남깁니다.
- `pipeline/normalize.py` 의 `EXCLUDE_SITES` 로 통합 데이터셋에서 제외
- `.gitignore` 로 공개 저장소에서 제외
- 수집 코드 `src/busansidae.py` 는 남겨 재현 가능하게 함

### 10. 중복 병합에서 일부러 남긴 것

회사·직무가 같아도 아래는 병합하지 않습니다. 중복이 아니라 실제로 다른 공고입니다.

| 예 | 차이 |
|---|---|
| 세움병원 간호 | 병동/외래, 간호사/수간호사/간호조무사, 야간전담 여부 |
| ㈜신건 배송 | 부산·울산·강원·경북 / 부산시 전지역 — 담당 권역 |
| 에스엠서치 상담 | KT / 롯데카드 / NH농협카드 — 고객사 |

`근무시간`·`근무형태`를 상세에서 확보하면서 이 판정이 더 정확해졌습니다.
