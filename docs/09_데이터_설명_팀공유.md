## 설계 원칙 두 가지

**① 원본을 지우지 않는다**

### `직무` 는 어떻게 만들었나

원본이 주는 것을 **6단계 우선순위**로 합칩니다. 앞쪽일수록 신뢰도가 높습니다.

```
1. 직종         사이트가 분류한 표준 명칭      → 그대로 신뢰
2. 직무키워드    사이트가 붙인 직무 코드        → 그대로 신뢰
3. 직무상세      모집분야                    ┐
4. 원본 직무 칸                              │ 직무 어휘 사전(약 350개)으로
5. 공고제목                                  │ 걸러서 사용
6. 담당업무 첫 문장                           ┘
```

공고제목도 직무 정보라서 씁니다. 다만 `모집합니다`·`채용 공고` 같은 **동사 꼬리말과
대괄호 안 회사명만 떼고** 내용은 남깁니다.

```
BNCT 터미널 지게차 기사 모집        →  BNCT 터미널 지게차 기사, 지게차, 기사
중등부 영어 파트 강사 모집           →  중등부 영어 파트 강사, 강사
[청목장애인활동지원센터] 사회복지사 채용 공고  →  사회복지사
```

`중등부 영어 파트` 같은 수식어가 남아 오히려 구체적입니다.
원문은 `공고제목` 컬럼에 그대로 보존됩니다.

### 채용인원을 세 칸으로 나눈 이유

표기가 사이트마다 다르고, **`0`·`○` 는 0명이 아니라 "안 밝힘"** 입니다.

```
모집인원원문   "1 명"   "○ 명"   "(3명)"    ← 사이트 표기 그대로
채용인원        1       (빈칸)     3        ← 숫자만
채용인원구분   명시      미정      명시       ← 집계 기준 선택용
```

미정을 0으로 잡으면 수요가 과소, 1로 잡으면 과대가 됩니다.
잡코리아는 절반이 `○ 명` 이라 이 구분이 특히 중요합니다.

# 7. 직종코드 — 사이트를 넘어 직무를 비교하려면

`직무` 는 사이트마다 태그 체계가 달라 그대로는 집계가 안 됩니다.

```
잡코리아  "국제금융, 금융, 은행, 문서관리, 전산입력, 서무, 행정"
사람인    "SNS마케팅, 광고마케팅, 바이럴마케팅"
커리어    "기구설계, 자동차부품개발, CATIA"
```

그래서 **한국고용직업분류(KECO) 직종코드**를 공통 키로 붙였습니다.
고용24 공식 분류표(대분류 13 · 중분류 114 · 세분류 1,215)가 기준입니다.

## 무엇이 붙었나

| 근거 | 건수 | 비중 | 부여 깊이 |
|---|---:|---:|---|
| 고용24 직접 | 2,559 | 10.1% | 세세분류 |
| 공식 명칭·별칭 일치 | 3,873 | 15.3% | 세세분류 |
| 정답에서 학습한 사전 | 579 | 2.3% | 세세분류 |
| 후보 분포 표결 | 14,411 | 57.0% | **대분류만** |
| 미분류 | 3,854 | 15.2% | — |

**세세분류까지 7,011건(27.7%) · 대분류까지 21,422건(84.8%)**

전 과정이 **결정적(deterministic)** 입니다. LLM·임베딩을 쓰지 않았습니다.
같은 공고가 실행마다 다른 코드를 받으면 사이트 간 비교가 무의미해집니다.

## 정확도를 실측했습니다

`직종` 컬럼 **2,559건이 공식 명칭과 완전일치**합니다(고용24 워크넷 연계분).
이걸 정답으로 두고, 라벨을 가린 뒤 나머지 경로만 돌려 5-fold 교차검증했습니다.

| `직종코드확실도` | 커버리지 | 대분류 | 세분류 |
|---|---:|---:|---:|
| **강 + 중** | 58.4% | **98%** | **95%** |
| 약 (대분류만 부여) | 37.8% | 72% | — |
| 미분류 | 3.8% | — | — |

**엄격하게 쓰려면 `직종코드확실도 = 강` 또는 `강+중` 만 쓰세요.**

## 미스매치 분석에는 그대로 쓰셔도 됩니다

건별 정확도보다 **비율이 안 틀어지는지**가 중요합니다.
정답 세트에서 실제 대분류 분포와 예측 분포의 차이는 **최대 1.0%p,
총변동거리 2.8%p** 였습니다. 건별로는 12%가 틀리지만 분포는 거의 그대로입니다.

## 조인은 라벨이 아니라 코드로 하세요

13대분류 명칭은 문서마다 다릅니다. 서현 문서의 `13 정보통신관련직` 과
공식 마스터의 `13 농림어업직` 은 **다른 체계**입니다.
학과↔직종 매핑은 **6자리 코드**를 키로 붙이고, 라벨은 `직종코드_계층표.csv`
에서 파생시키세요.

또 공식 분류표는 트리가 아니라 **DAG** 입니다. 세분류 79개가 중분류 2곳 이상에
걸려 있고 그중 67개는 대분류가 갈립니다(`026502 병원행정 사무원` → 경영·사무 **및**
보건·의료). 그래서 **대분류 집계는 6자리 코드의 앞 1자리(10개)** 를 쓰고,
공식 13대분류는 참고 컬럼으로만 실었습니다. 앞 1자리는 코드 1개당 상위 1개라
겹치지 않습니다.
