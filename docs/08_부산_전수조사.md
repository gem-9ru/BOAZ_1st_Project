# 부산 지역 전수 조사

**조사일** 2026-09-08 · **도구** `src/audit/busan_audit.py` + 브라우저 네트워크 관찰

이 데이터셋의 목적은 **부산 지역 채용 수요 파악**입니다.
그런데 초기 수집은 "전국을 받아서 부산을 걸러낸다" 는 방식이었고, 그게 틀렸습니다.

---

## 왜 전국 수집 후 필터링이 실패하는가

채용공고는 근무지가 여러 곳일 수 있습니다. 그런데 상세페이지의 구조화 데이터는 주소를 하나만 줍니다.

```
실제 공고        "서울, 경기, 대구, 경북, 부산, 경남"   ← 6개 지역
JSON-LD         jobLocation.address.streetAddress   ← 1개만
우리가 기록한 값   "서울 중구"
결과            부산 집계에서 탈락
```

부산 근무가 가능한 공고인데 통째로 빠집니다. 실측 결과입니다.

| 사이트 | 전국 수집 후 필터 | 지역 필터 직접 | 결손 |
|---|---:|---:|---:|
| 잡코리아 | 4,149 | **8,671** | −4,511 (52%) |
| 커리어 | 852 | **5,070** | −4,357 (84%) |
| 사람인 | 12,214 (간접) | **13,946** | −1,732 |
| 널스케이프 | 0 | **49** | −49 (100%) |

**→ 원칙: 지역이 목적이면 사이트의 지역 필터를 직접 씁니다.**

대신 전수 수집이 실제로 전수인지 정본 대조로 확인했습니다.

## 교차 검증 — 제목엔 부산, 지역칸엔 없음

지역 칸에 **본사 주소**가 적히고 실제 근무지는 부산인 공고가 있습니다.
전 사이트에서 제목·회사명에 부산 지명이 있으나 지역 칸에 부산이 없는 행을 세어봤습니다.

| 사이트 | 건수 | 예 |
|---|---:|---|
| 잡코리아 | 196 | 지역칸이 본사 주소 |
| 잡코리아추가 | 41 | 〃 |
| 자소설닷컴 | 31 | 지역 필드 자체가 없음 |
| 잡알리오 | 26 | "부산울산경남지역협력단" → 지역칸 경남 |
| 커리어 | 16 | |
| 캐치 | 5 · 원티드 4 · 리멤버 3 · 나라일터 2 | 다지역 공고 |

→ `pipeline/extract_busan.py` 에 **제목·상세주소 기반 판정**을 추가했습니다.
사이트별 특례가 아니라 전 사이트 공통 규칙입니다.

```python
BUSAN_WORD = re.compile(r"부산|해운대|센텀시티|센텀|광안리|남포동|자갈치|서면역|"
                        r"동래구|금정구|연제구|수영구|영도구|사하구|부산진구|기장군|사상구")
```

**의도적으로 뺀 지명**
- `기장` — "세무기장" 이 훨씬 흔합니다
- `사상` — "사상 최대" 등
- `남구·동구·중구·서구·북구` — 다른 광역시에도 같은 이름이 있습니다

부산 지역 필터로 새로 받은 잡코리아·커리어는 이 교차검증에서 **0건**이 나왔습니다.
지역 필터가 제대로 작동했다는 뜻입니다.

## 부산 특화 사이트를 따로 찾아봤다

"부산일자리정보망 말고 부산 특화 사이트가 더 있는가" 를 전수 조사했습니다.

| 사이트 | 결과 |
|---|---|
| 부산장애인일자리정보망 `busanjob4u.net` | **124건** — 부산시 운영, busanjob.net 자매. 목록에 직무 명시 |
| 잡부산시대 `job.busansidae.com` | **170건** — 부산 전용 상용. 재배포 금지 고지로 데이터셋 제외 |
| 부산광역시 채용공고 `busan.go.kr/nbincruit` | 부산일자리정보망·나라일터와 중복 |
| 청년부산잡스 / 시니어부산잡스 | busanjob.net 하위 메뉴, 같은 DB |
| 부산일포유 `bsjob4u.co.kr` | 일자리 **정책** 안내, 공고 없음 |
| 부산경제진흥원 / 부산상의 / 부산테크노파크 | 기관 홈페이지, 채용 게시판 없음 |
| 장노년일자리지원센터 / 여성새로일하기센터 | 전국 단위(고용부·여가부), 부산 전용 아님 |

**결론: 부산 특화 사이트로 전환할 근거는 없습니다.**

```
부산일자리정보망  25,895      부산 특화 신규       124  (0.5%)
사람인 부산       13,946
잡코리아 부산      8,671
커리어 부산        5,070
```

부산 공고의 대부분은 전국 사이트의 지역 필터에 있습니다.
부산 특화 사이트는 보완재로 넣습니다.

> **커리어도 같은 함정이 있었습니다.** 필터 패널은 부산 5,209건이라 표기하지만
> 목록은 102페이지(약 5,072건)에서 끝납니다. 패널 숫자가 누적치였습니다.
> 수집분 5,070건이 사실상 전수입니다.
>
> 잡부산시대는 처음에 필터 패널의 업종별 숫자를 합해 8,523건으로 봤는데,
> JSON API 의 `totalnum` 으로 확인하니 활성 공고는 **207건**(고유 170건)이었습니다.
> 패널 숫자는 누적치였습니다. **사이트가 보여주는 숫자도 무엇을 세는지 확인해야 합니다.**

## 조사 중 발견한 수집 결함

| 결함 | 사이트 | 원인 |
|---|---|---|
| 부산 0건 | 널스케이프 | 목록 **첫 페이지만** 읽고 페이지네이션이 없었다 |
| 84% 결손 | 커리어 | 슬라이스마다 `MAX_PAGE=12`(600건) 인위적 상한 |
| 52% 결손 | 잡코리아 | 다지역 공고를 첫 주소로만 기록 |
| 학력·급여 유실 | 잡코리아·사람인 | `Site.save()` 가 고정 12칸만 쓰고 나머지를 버렸다 |
| 페이지네이션 무효 | 잡코리아 | `Page`/`Page_No` 파라미터가 안 먹는다. 실제로는 POST API |
| 알바 469건 혼입 | 잡코리아 부산 | 목록에 알바몬 링크가 섞여 온다. `data-gno` 자릿수로 구분(9자리=알바몬) |
| IP 차단 | 사람인 | 4워커 3req/s 로 6,400건 → TCP connect 차단 |

마지막 두 개가 특히 위험했습니다. 로그에는 "학력 8,639건" 으로 찍히는데
CSV 에는 그 컬럼이 아예 없었습니다. **로그가 아니라 결과 파일을 봐야 합니다.**
