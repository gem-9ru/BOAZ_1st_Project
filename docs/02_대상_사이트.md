# 대상 사이트별 수집 방식

각각 데이터를 꺼내는 경로와 주의점이 다릅니다.

> **부산 지역 전용 크롤러**
> 이 데이터셋의 목적이 부산이라, 규모가 큰 사이트는 **지역 필터로 다시 받았습니다.**
> 전국 수집 후 필터링하면 다지역 공고가 통째로 빠지기 때문입니다.
> 사이트별 접근 경로와 정본 대조는 [08_부산_전수조사.md](08_부산_전수조사.md) 참조.
>
> | 부산 전용 | 파일 | 건수 |
> |---|---|---:|
> | 사람인 | `src/saramin_busan.py` | 13,946 |
> | 잡코리아 | `src/jobkorea_busan.py` | 8,666 |
> | 커리어 | `src/career_busan.py` | 5,070 |
> | 널스케이프 | `src/nurscape_busan.py` | 49 |
>
> **직무 상세 보강** — 목록은 '빠짐없이 찾는' 단계, 상세는 '깊이' 단계입니다.
> 목록의 직무 태그로 상세를 대체하지 않습니다.
> `src/busanjob_detail.py` (부산일자리정보망) · `src/duty_detail.py` (그 외 전 사이트)

## 종합 채용

### 사람인 — `src/saramin_busan.py` · 부산 13,946건
그동안 직접 수집하지 않고 부산일자리정보망이 재노출하는 12,214건만 갖고 있었습니다.
그쪽 목록은 직무를 안 줘서 직무 정보가 통째로 비어 있었습니다.

```
/zf_user/jobs/list/domestic?loc_mcd=106000&page={N}&page_count=100
```

목록 한 행(`div.list_item`)에 직무 태그·근무지·경력·고용형태·**학력**·마감일이 다 있습니다.

- `.job_sector span` → 직무 태그 ("SNS마케팅, 광고마케팅, 바이럴마케팅, 콘텐츠마케팅")
- `.career` 는 경력과 고용형태가 한 칸에 붙어 옵니다.
  `"경력무관 · 계약직"` 2조각, `"신입 · 경력 · 정규직"` 3조각 — 앞에서 자르면 안 됩니다.
  뒤에서부터 고용형태 어휘에 걸리는 조각만 떼어냅니다
- 상세는 `/zf_user/jobs/relay/view-detail?rec_idx=` (9KB). `popup`(431KB)과 같은 내용입니다

### 잡코리아 부산 — `src/jobkorea_busan.py` · 8,666건
전국 sitemap 수집분에서 부산은 4,149건이었는데 지역 필터로는 **8,660건**입니다.
다지역 공고("서울, 경기, 대구, 경북, 부산, 경남")가 첫 주소로만 기록돼 빠졌습니다.

```
진입  /recruit/joblist?menucode=local&localorder=1&local=H000   ← 세션에 검색조건 등록
페이저 POST /Recruit/Home/_GI_List/
      page=N&condition[local]=H000&pagesize=100&order=20&…
```

**URL 파라미터(`Page`/`Page_No`)는 안 먹습니다.** 몇 페이지를 요청해도 1페이지가 옵니다.
브라우저 네트워크를 떠서 실제 페이저가 POST 인 것을 확인했습니다.

목록 한 행(`tr.devloopArea`)에 들어 있는 것:

- `p.dsc` → 직무 태그 전량 ("국제금융, 금융, 은행, 문서관리, 전산입력, 서무, 행정, …")
- `p.etc .cell` → 경력 / **학력** / 지역 / 고용형태 / 급여.
  칸 개수와 순서가 공고마다 달라서 위치가 아니라 내용으로 판별합니다
- `data-gainfo` 의 `dimension46` → **전체 근무지역 목록**. 목록 셀은 "부산 전지역 외" 로 잘립니다

> **상세요강(담당업무)은 메인 페이지에 없다**
> ```
> /Recruit/GI_Read/{gno}                  ← '상세요강' 제목만, 내용은 비어 있음
> /Recruit/GI_Read_Comt_Ifrm?Gno={gno}    ← 담당업무 본문은 여기
> ```
> `src/duty_detail.py` 가 공고당 2요청으로 둘 다 받는다.
>
> **목록 링크가 세 종류다.** `data-gno` 로 URL 을 조립하면 절반이 404 다.
> ```
> 8자리  /Recruit/GI_Read/{gno}                     잡코리아 자체   3,979
> 7자리  /Recruit/GI_Read/{gno}/Ext?siteCode=WN     워크넷 연계     4,213
> 9자리  https://www.albamon.com/jobs/detail/{gno}  알바몬 = 알바      469
> ```
> 워크넷 연계는 레이아웃이 완전히 달라 전용 파서(`p_jobkorea_ext`)가 필요하다.
> 알바몬 링크는 `외부원본ID` 를 `albamon:` 으로 남겨 정규화 단계가 제외한다.

### 잡코리아 (전국) — `src/jobkorea.py` · 107,812건
sitemap(agi) 으로 전체 공고 URL 을 확보한 뒤 상세페이지의 JSON-LD `JobPosting` 을 파싱합니다.
sitemap 기반이라 전수가 보장됩니다.

- `occupationalCategory` → 직무, `validThrough` → 마감일, `experienceRequirements` → 경력
- JSON-LD 에 직무가 없으면 본문의 "모집분야" 항목에서 추출

### 커리어 부산 — `src/career_busan.py` · 5,070건
기존 수집은 지역·직무 슬라이스마다 `MAX_PAGE=12`(600건) 상한을 걸어둬서
부산이 852건에서 잘렸습니다. 사이트 표기는 **5,209건**입니다.

"목록 100건 캡" 이라는 초기 진단을 슬라이스에도 적용한 게 원인이었습니다.
실측해보니 지역 슬라이스는 page 100 까지 정상 동작합니다.

```
/jobs/area?i_ac=9&page={N}&i_pagesize=50      i_ac=9 가 부산
```

> **부산분은 상세가 비어 있다.** 표본 25건이 전부 워크넷 연계였고
> 담당업무·관련키워드·업종이 하나도 없다. 워크넷 ID 도 노출하지 않는다.
> 목록의 해시태그 24%(1,455건)가 이 사이트에서 얻을 수 있는 직무 정보의 전부다.

## 지역 — 부산 특화

전국 사이트의 부산 필터가 부산 공고의 대부분을 담고 있지만,
지역 소규모 업체·장애인 채용처럼 전국 사이트에 안 올라오는 자리가 있어 함께 수집합니다.

### 부산장애인일자리정보망 — `src/busanjob4u.py` · 124건
부산광역시가 운영하는 장애인 채용 포털. 부산일자리정보망의 자매 사이트로 CMS 가 같습니다.

```
/view.do?no=122&pgMode=index&pageIndex={N}      페이지당 12건, 13페이지
```

**목록에 직무가 명시**돼 있어 직무 데이터 품질이 좋습니다 (채움률 100%).

```
li.jobs_panel_item
  h5.corp_name        회사명        h5.panel_title   공고제목
  dl.location dd      근무지역       dl.Job dd        직무 "기물세척 및 관리"
  dl.date dd          모집기간       a onclick="show('2485','CP')"  공고 ID
```

인증서 체인이 불완전해 `verify=False` 가 필요합니다(공공 사이트).

### 잡부산시대 — `src/busansidae.py` · 170건 · **통합 데이터셋 제외**
부산 전용 상용 사이트. 목록이 JS 렌더링이라 JSON API 를 씁니다.

```
/employ/ajax/json.linead.html?page={N}[&cate={코드}]
  -> {"response":{"data":[...], "totalpage":11, "totalnum":207}}
```

사이트는 207건이라 표기하지만 페이지 6~11 에 중복이 섞여 **고유 공고는 170건**입니다.
페이지 인코딩이 EUC-KR 입니다.

> **재배포 금지 고지가 있어 통합 데이터셋과 공개 저장소에서 뺐습니다.**
> 수집분은 `data/잡부산시대.csv` 로 로컬에만 남아 있습니다.
> → [03_정책감사.md](03_정책감사.md) ①, [06_알려진_한계.md](06_알려진_한계.md)

### 부산일자리정보망 — `src/busanjob.py` · 25,895건
부산광역시가 운영하는 공공 포털. 서버 렌더링이라 정적 HTML 에 목록이 들어 있습니다.

```
/view.do?no={메뉴}&pgMode=index&pageIndex={N}
  no=1308 기업채용 / 1309 공공채용 / 1310 해외채용
```

- 항목 셀렉터 `ul.emif-lst > li`, 페이지당 12건
- **메뉴마다 링크 방식이 다릅니다.** 기업·공공채용은 `onclick="show('817303')"` 내부 링크,
  해외채용만 월드잡플러스 외부 href 를 직접 겁니다. 해외채용은 필드 배치도 달라
  `.item` 첫 칸이 직무, `.batcont.country` 가 국가입니다
- **자체 공고가 아닙니다.** 사람인·잡코리아·고용24·알리오 공고를 함께 노출하며
  `provide-bat` 클래스가 출처를 알려줍니다. 이 값을 `외부원본ID` 로 보존해
  중복 판정 근거로 씁니다

출처 분포: 사람인 15,519 / 잡코리아 5,751 / 워크넷 3,965 / 해외 569 / 알리오 53 / 수동 20 / 부산자체 18

> 현재 **목록만** 수집하고 상세페이지는 받지 않았습니다. 이 때문에 직무·고용형태에
> 결손이 있습니다. → [06_알려진_한계.md](06_알려진_한계.md)
