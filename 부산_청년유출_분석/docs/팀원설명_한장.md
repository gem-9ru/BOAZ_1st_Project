# 부산 청년 유출 — 우리가 한 것

## 과정

주제를 세 질문으로 쪼갰다.

```
① 청년이 정말 나갔나        ② 이유가 일자리인가        ③ 왜 일자리가 없나
```

처음 가진 데이터(채용공고·졸업자통계)로는 ③만 답할 수 있었다. 그래서 6개를 더 붙였다.

| 붙인 것 | 무엇에 썼나 |
|---|---|
| 국내인구이동통계 2022~25 | 실제로 나갔는지, 왜 나갔는지 |
| 고용24 구인구직 12개월 | 부산 노동수요 (공공 채널) |
| GOMS 2016~19 4개 코호트 | 개인 단위 추적 — 어디 취업했고 얼마 벌었나 |
| 전국사업체조사·사업체노동력조사 | 부산 임금·기업 규모 |
| 주민등록 인구 | 인구 대비 보정 |
| 부산 청년정책 시행계획 | 정책이 어디를 겨냥하나 |

**모든 데이터를 하나의 축으로 이었다** — 학과는 KECO 직종코드로, 수요도 KECO로, 정책도 계열로.
단위가 다 달라서(연간 / 12개월 / 하루) **절대수를 버리고 구성비만** 비교했다.

---

## 결과

**① 나갔다 — 부산만의 모양으로**
20-24세 **+927** (들어옴) → 25-29세 **−5,437** (나감). 전환폭은 2위 대전의 3.5배.
**20대 초반이 순유입인 비수도권 광역시는 부산뿐이다.**

**② 이유는 직업이다**
순유출 사유의 **74.4%가 직업**, 주택은 17.4%. 교육은 오히려 +3,479 순유입.

**③ 떠난 사람이 실제로 더 번다**
부산 대학 졸업자 **44.6%가 부산 밖**에 첫 자리. 부산 출신도 31% 떠났다.
개인 특성 다 통제해도 **+14.2%** 남는다. 사업체 통계의 부산-서울 임금 격차 **14.4%** 와 거의 같다.

**④ 남은 일자리의 결이 다르다**
부산 노동수요의 **59%가 보건복지·제조** 두 산업. 정보통신업 종사자는 **서울의 3.9%**.
300인 이상 사업체 종사자 비중 **부산 12.2% vs 서울 24.5%**.

**⑤ 그런데 정책은 반대쪽에 있다**
계열이 명시된 32개 사업 중 **양성 22 : 매칭 3**. 예산은 교육 57.6% : 일자리 12.8%.

---

## 그래서 결론

> ### 부산은 청년을 가장 많이 잃는 도시가 아니다. **모았다가 잃는 유일한 도시**다.
> ### 이유는 집값도 대학의 실패도 아니라 **일자리의 결**이다.

계열마다 나타나는 방식이 다르다.

```
기계·전기전자  →  떠난다        (이탈 56%, 떠나면 +26%)
물류·운송      →  떠난다        (이탈 58%, 떠나면 +26%)
IT·컴퓨터      →  수도권으로     (수도권행 24.6%로 1위, 부산에 산업이 없어서)
디자인·예술    →  못 떠난다      (떠나도 +5%, 남아서 월 175만원)
보건·의료      →  안 떠난다      (부산에서도 같은 돈)
```

**미스매치는 유출로만 나타나지 않는다. 하향취업으로도 나타난다.**

## 발표에서 먼저 꺼낼 것

우리가 **틀렸다가 고친 것 8개**가 있다. 심사에서 찔릴 곳을 우리가 먼저 말한다.

| 처음 | 고친 뒤 |
|---|---|
| "3.41배 과잉 배출" | 정의 바꾸면 0.84~3.95배 → **배율 주장 폐기** |
| "전국 1위" | 인구 보정하면 광주가 위 → **"모았다가 잃는 유일한 곳"** |
| "대기업 부재 가설 기각" | 지표를 잘못 골랐음 → **300인 이상 비중으로 보니 가설 성립** |
| "7개 계열 전부 임금 우위" | 통제하면 일부만 유의 |
