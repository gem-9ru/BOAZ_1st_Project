## 1. 회의에서 먼저 합의해야 할 3가지 (여기서 안 잡으면 뒤가 다 무너짐)

### ① 우리 데이터에는 "유출"이 없다
취업통계 94컬럼 어디에도 **취업 지역**이 없다. 즉 부산 졸업생이 어디로 갔는지 이 파일로는 못 본다.
→ 지금 구조로 증명 가능한 것은 **"부산 일자리 구성이 부산 졸업생 구성과 어긋나 있다"**(원인 측)까지다.
→ 결과 측(실제 유출량)은 **외부 데이터 1개를 반드시 붙여야 한다.**

| 후보 | 얻는 것 | 난이도 |
|---|---|---|
| 통계청 국내인구이동통계 (시도·연령별 순이동) | 부산 20대 순유출 추이 — **결과 지표** | 쉬움(KOSIS 즉시) |
| 대졸자직업이동경로조사(GOMS) | 졸업 후 근무지 시도 — **직접 증거** | 신청 필요, 본선용 |
| 취업통계 유지취업률(내장) | 일자리의 질 프록시 | 이미 있음 |

**제안: 서류(9/18)는 KOSIS 순유출 1장 + 우리 미스매치 분석. GOMS는 본선(9/23~10/29)에서 붙인다.**

### ② 절대수 비교 금지 — 구성비로만 본다
졸업자 36,996명(1년 flow) vs 공고 25,135건(하루 stock). **단위가 다르다.**
"졸업자 3.7만 vs 일자리 2.5만" 같은 문장은 심사에서 바로 깨진다.
→ 모든 비교는 **구성비(%) 대 구성비(%)**. 축은 "양"이 아니라 **"결"**.
→ 주제문의 "엇갈린 결"이 정확히 이 설계다. 주제를 데이터가 할 수 있는 것에 맞춘 셈.

### ③ 학력 필터의 함정
- 대졸 이상 명시: **2,315건 (9.2%)**
- 학력무관: **14,996건 (60%)**
→ "대졸 공고만" 필터하면 표본 90%를 버리고 편향된다. 반대로 전부 쓰면 대졸 수요가 아니다.
**해법: 2가지 정의를 병기하고 민감도 분석으로 제시한다.**
- 엄격(A): 요구학력 = 대학교졸·석사이상 → 2,315건
- 완화(B): A + 학력무관 중 대졸요구율 40%↑ 직종대분류(연구·공학, 교육·법률·복지, 보건·의료)
→ 두 정의에서 결론이 같으면 그게 논문급 방어력이 된다.

## 2. 분석 3층 구조 (스토리 = 이 순서)

```
L0  배출과 수요의 결이 다르다        ← 구성비 비교   (미스매치의 "형태")
L1  남는 일자리는 질이 다르다         ← 임금·고용형태·신입 (미스매치의 "질")
L2  그래서 떠난다                   ← 외부 순유출 지표  (결과와의 연결)
```

### L0 — 배출 vs 수요 구성비
- 축: **직종 대분류 10종**(공고 97% 커버). 학과는 서현의 그룹계열 13종 → 10종으로 접는다.
- **조인은 반드시 6자리 직종코드.** 라벨 조인 금지(서현 13대분류와 고용24 13대분류는 다른 체계).
- 산출: 발산형 막대(좌 졸업자% / 우 공고%) + 과잉/과소 배율(LQ, Location Quotient)

미리 돌려본 신호 (확정 아님, 방향만):

| 계열/직종 | 배출 비중 | 부산 공고 비중 | 결 |
|---|---:|---:|---|
| 디자인·예술 | 11.9% | 3.5% | **과잉 3.4배** |
| IT·컴퓨터 | 5.2% | (연구·공학 9.0% 안에 극소수) | **심각한 과잉** |
| 경영·사무 | 28.0% | 24.6% | 비슷 |
| 보건·의료 | 11.6% | 13.4% | 균형 |
| 미용·돌봄·청소 | (배출 없음) | **15.9%** | **대졸이 갈 수 없는 수요** |
| 설치·정비·생산 | (기계·전기전자 13.3%) | 15.9% | 양은 있으나 대졸요구 7.6% |

> IT 수치 주의: 세세분류 확보분 8,670건 중 IT 관련 136건(1.6%)인데, 이 표본이 고용24 연계분(요양·제조 편중)이라 **IT가 과소추정됐을 수 있다.** 서류 제출 전 사람인·원티드·점핏 표본으로 교차검증 필요. **이 숫자가 우리 논지의 핵심이라 여기가 가장 큰 리스크다.**

### L1 — 남아 있는 일자리의 질
같은 직종 대분류 **안에서** 비교한다. (전체 중앙값 비교는 반박당한다 — 급여 명시율이 직종마다 14.8%~65.8%로 달라 저임금 쪽으로 편향)
- 대졸요구 직종 3개(연구·공학, 교육·법률·복지, 보건·의료) 합계 = **전체 공고의 29.0%**
- 연봉 중앙값: 연구·공학 3,500 / 교육·법률·복지 2,760 / 미용·돌봄 2,588(최저임금 연환산)
- **가장 센 숫자: 대졸명시 + 신입·무관 + 정규직 = 816건** (하루 스냅샷)
  → 강력하지만 위험하다. 연환산 가정(평균 게재기간)을 명시하지 않으면 못 쓴다. **게재~마감일로 duration 추정해서 연간 환산치를 내는 걸 누가 맡을지 정할 것.**
- 신입가능율: 연구·공학 **45.0%** (최하위) — 부산 공학 일자리는 경력직 시장

### L2 — 유출과의 연결
- KOSIS 부산 20대 순유출 추이 ↔ L0 과잉 계열 매칭
- 취업통계 내장 지표로 보조: 4차 유지취업률(취업자 대비) — 예체능 **44.8%**, 공학 77.1%, 의약 76.1%
  → 과잉 배출 계열이 유지취업률도 낮다. **"일자리를 못 찾는 게 아니라 붙어 있지 못한다"** 가 두 번째 논지.
- 진학률: 자연계열 16.8%(최고) — 학부 수요 부재를 대학원으로 흡수하는 경로. 이것도 유출 예비군.

## 4. 최종 산출물 (그림 5장으로 끝낸다)

1. **엇갈린 결** — 발산형 막대: 학과 배출% ↔ 직종 수요% (메인 비주얼, 주제문 그 자체)
2. **과잉/과소 지도** — LQ 버블: x=배출비중, y=수요비중, 45도선 이탈이 미스매치
3. **남은 일자리의 질** — 직종별 연봉중앙값 × 대졸요구율 산점도, 버블=공고수
4. **떠나는 이유** — 과잉 계열의 유지취업률 vs 균형 계열
5. **결과** — 부산 20대 순유출 시계열에 1~4 주석

## 6. 심사에서 나올 질문 (미리 답을 준비)

| 질문 | 우리 답 |
|---|---|
| "하루 공고로 1년 수요를 말할 수 있나?" | 절대수 안 씀. 구성비만. + duration 연환산 보조지표 |

## 7. 내가 보는 가장 큰 리스크

1. **IT 과소추정** — 논지의 핵심인데 표본 편향 가능성이 있다. 교차검증 전에는 IT를 헤드라인으로 쓰지 말 것.
2. **크로스워크가 곧 결론** — 인문·생활과학을 어디 붙이냐로 미스매치 크기가 바뀐다. 자의적으로 보이면 전체가 무너진다. **매핑 근거를 문서로 남기고, 대안 매핑으로 민감도 분석 1회 돌릴 것.**
3. **심사기준 미확인** — 배점을 모르고 설계 중이다. 오늘 중 확인.
