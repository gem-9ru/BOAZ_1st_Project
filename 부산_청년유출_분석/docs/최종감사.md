# 최종 감사 — 출품 가능한가, 무엇이 남았는가

세 질문에 답한다. ① 이대로 출품 가능한가 ② BOAZ까지 디벨롭 여지 ③ 억측·근거 부족은 없는가
**추정이 아니라 실제로 다시 돌려서 확인했다.**

---

## Ⅰ. 출품 판단 — **가능하다. 단 미결 2개가 있다.**

| | 항목 | 상태 |
|---|---|---|
| 분석 | 9층 완결 · 114 시나리오 민감도 · 교차검증 2건 | ✅ 충분 |
| 데이터 | 원본 3 + 외부 6, 모두 공개·재현 가능 | ✅ |
| 재현성 | `build/` 스크립트로 원자료 → 결과 전부 재생성 | ✅ |
| 시각화 | 그림 6장 + 대시보드 시안 (Tableau 제작 예정) | ⚠ **Tableau 미제작** |
| **제안(처방)** | 정책 진단까지. **"그래서 무엇을 하자"가 한 문단** | ⚠ **얇다** |
| **대회 요건** | **심사기준·배점·제출형식 미확인** | ⚠ **외부 확인 필요** |

### 미결 ① 심사기준을 모르고 만들었다
대회 홈페이지에 배점이 없다. **지금까지 우리가 추정한 심사 관점으로 설계했다.**
분석 비중이 높은 심사면 유리하고, 서비스 구현 비중이 높으면 Tableau 완성이 필수다.
→ **운영측 문의 또는 공고문 PDF 확인이 제출 전 최우선.**

### 미결 ② 제안이 진단에 비해 얇다
대회는 *"아이디어 제안 또는 데이터 기반 서비스 기획"* 을 요구한다.
우리는 **"정책이 양성 22 : 매칭 3으로 어긋나 있다"** 까지 갔고,
**"그래서 무엇을 어떻게 바꾸자"** 는 한 문단이다. 진단이 정교할수록 이 불균형이 눈에 띈다.

### ⚠ 성별 — 돌려봤더니 차이가 크다

| | 표본 | 이탈률 | 수도권 | 잔류 월소득 | 이탈 월소득 |
|---|---:|---:|---:|---:|---:|
| **남** | 2,987 | **47.1%** | 13.5% | 230만원 | 260만원 |
| **여** | 2,532 | **34.2%** | 11.6% | **185만원** | 200만원 |

인구이동에서도 25-29세 순유출이 **남 −3,239 / 여 −2,198**로 갈린다.

```
남성은 더 많이 떠나고, 떠나서 더 번다 (+30만원)
여성은 덜 떠나고, 남으면 월 185만원을 받는다 (남성 잔류자보다 45만원 낮다)
```

**우리는 성별을 회귀의 통제변수로만 넣었고 분석 축으로 본 적이 없다.**
여성 잔류자 월 185만원은 그 자체로 강한 발견인데 지금 어디에도 없다.

> **이건 빠뜨린 것이지 못 한 것이 아니다. 데이터는 이미 있다.**

## Ⅲ. 억측·근거 부족 — 실제로 찾은 6개

### 1. [수정 필요] "구직자 N명당 자리 1개" — 실제는 **건수**다

고용24 원표 이름이 **`신규구직건수`** 다. 한 사람이 기간 내 여러 번 신청하면 복수로 계상된다.

```
(현재) 예술·디자인 0.06 — 구직자 16명당 자리 1개
(정확) 예술·디자인 0.06 — 구직 신청 16건당 자리 1개
```

**5개 문서·화면에 이 표현이 들어가 있다.** 심사위원이 원표를 열면 바로 지적당한다.
→ *"구직 신청 N건당"* 으로 바꾸거나, 각주로 *"고용정보원은 이를 구직자 1인당 일자리수로 해석한다"* 를 단다.

### 2. [약함] "20년 누적 186,499명 = 연간 졸업자의 5배"

**20년 누적(stock)을 1년 졸업자(flow)로 나눈 것**이다. 단위가 다르다.
숫자가 커 보이게 하는 수사이지 의미 있는 비율이 아니다.
→ *"20년간 18만 6천 명"* 까지만 쓰고 배수 비교는 뺀다.

### 3. [약함] "매년 기존 종사자의 10.7%를 새로 배출한다"

컴퓨터·통신 졸업자 1,917명 ÷ 부산 정보통신업 종사자 17,989명.
**분자는 졸업자 전원(전원이 IT로 가지 않는다), 분모는 전 학력 종사자**다. 비교가 거칠다.
→ 방향성 서술로만 쓰고 퍼센트는 각주로 내린다.

### 4. [검증 안 됨] 정책 109개의 계열 분류

**사업명 키워드 정규식으로 분류했다.** 32개에 계열을 붙였는데 팀 검토를 안 거쳤다.
특히 **조선해양플랜트를 기계·전기전자로** 뒀는데 물류·운송으로 볼 여지가 있다.
→ `out/정책_계열분류.csv`를 팀이 한 번 훑어야 한다. **30분이면 된다.**

### 5. [반올림] 대시보드 "10명 중 5명이 떠났다"

46.4%를 5명으로 반올림했다. 쉬운 말로 바꾸는 과정에서 정밀도를 잃는다.
→ 툴팁에 원값(46.4%)을 함께 띄운다(이미 그렇게 돼 있으나 본문에도 병기 권장).

### 6. [프레이밍] "부산은 교육으로 불러들이고 직업으로 내보낸다"

각주를 달아 뒀지만, **교육 순유입 +3,479의 대부분은 대학 입학**이다.
대학이 있는 비수도권 광역시면 대체로 나타난다.
→ 각주는 유지하되 **발표에서 이 문장을 단독으로 쓰지 않는다.**

## Ⅳ. BOAZ 발표(10/05)까지 디벨롭 여지 — **크다**

우선순위 순. 1~3은 **데이터가 이미 있어 추가 수집이 없다.**

| | 작업 | 소요 | 왜 |
|---|---|---|---|
| **1** | **성별 축 추가** | 반나절 | MECE 최대 구멍. 여성 잔류자 185만원은 독립된 발견 |
| **2** | **비임금 요인** (GOMS 만족도 13문항) | 반나절 | "임금만 보느냐"는 반론 차단. 잔류자가 무엇에 불만인지 |
| **3** | **유입 분석** (전입 362,416명) | 반나절 | 순이동만 보면 "누가 들어오는가"를 놓친다 |
| **4** | 표현 수정 6개 (Ⅲ절) | 1시간 | 지적당할 곳 제거 |
| **5** | 정책 분류 팀 검토 | 30분 | 자의성 제거 |
| **6** | **제안 파트 정교화** | 1일 | 대회 요구사항. 국비 구조 프레이밍은 이미 있음 |
| **7** | **Tableau 구현** | 3일 | 최종 산출물 |
| 8 | 고졸 청년 (지역별고용조사) | 2일 | 범위 확장. 선택 |
| 9 | 본사 기능 (기업통계) | 미정 | 데이터 확보부터 |

**1~5는 합쳐서 이틀이 안 된다.** 출품(9/18) 전에도 가능하다.

## Ⅴ. 결론

### 출품 여부
> **출품해도 된다.** 분석의 완결성·재현성·자기검증은 공모전 수준을 넘는다.
> 다만 **제출 전에 반드시 둘**: ① 심사기준 확인 ② Ⅲ절의 표현 6개 수정.

### 가장 큰 위험은 "틀린 것"이 아니라 "빠진 것"이다
억측은 거의 없다. 8개를 이미 스스로 잡아 고쳤다.
**진짜 약점은 성별을 한 번도 안 본 것**이고, 이건 반나절이면 메운다.

### 제안 파트의 불균형
진단 9층 : 제안 1문단. 심사위원이 *"그래서 뭘 하라는 건가"* 라고 물으면
지금은 **"시비 재량분을 수요 쪽으로"** 한 줄뿐이다.
**BOAZ까지 이 비율을 바꾸는 것이 가장 큰 개선 여지다.**
