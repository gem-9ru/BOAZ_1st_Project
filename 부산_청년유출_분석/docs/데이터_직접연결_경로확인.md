# "졸업자가 어디로 갔는가" — 직접 연결 경로 확인 결과

2차 결과의 한계였던 **"순이동은 졸업자 추적이 아니다"** 를 풀 수 있는지 확인했다.
결론: **공식 통계로는 불가능하고, GOMS 하나만 가능하다. 그리고 GOMS에는 필요한 게 다 있다.**

---

## 1. 막힌 길 두 개 (확인 완료, 더 찾지 말 것)

### ① 고등교육기관 졸업자 일자리이동통계 — 지역 축이 없다

KOSIS 수록 32개 표를 전수 확인했다. 축은 4가지뿐이다.

```
학교소재지별 × 기업규모간 / 산업대분류간 / 조직형태간 / 종사자규모간
학교유형별   × (동일 4종)
교육분류별   × (동일 4종)
성별        × (동일 4종)
```

**지역은 "학교소재지" 하나뿐이고, "직장 소재지"가 없다.**
즉 이 통계의 "이동"은 **지역 이동이 아니라 직장 이동**(이직)이다. 우리가 찾던 것이 아니다.

### ② 취업통계 본체 — 취업 지역 항목 자체가 없다

조사 항목에 있는 지역 변수는 `출신고교 지역` `우편번호·집주소` 뿐이고,
지역 관련 공표 지표는 **학교 소재지 기준 취업률·유지취업률**(수도권 71.3% / 비수도권 67.7%)까지다.
우리가 쓰는 2024 엑셀의 94개 컬럼에 취업 지역이 없던 것과 일치한다.

> **회의 메모: 이 두 경로는 닫혔다.** 팀에서 더 뒤지지 말자.
> "왜 졸업자를 직접 추적 안 했나"는 질문에는 **"공식 통계에 그 축이 없다"** 가 정답이고,
> 그걸 확인했다는 사실 자체가 보고서의 신뢰도를 올린다.

## 2. 열린 길 — GOMS 대졸자직업이동경로조사

`2019GOMS1` 코드북(1,300여 변수)을 열어 확인했다. **필요한 변수가 전부 있다.**

| 변수 | 내용 | 쓰임 |
|---|---|---|
| `g191area` | 학교소재지역 | **부산 소재 대학 졸업자 필터** |
| `g191d020` | **D7. 첫직장 사업체 위치 시도** | **졸업 후 첫 일자리가 어디인가 — 핵심** |
| `g191a014` | A6. 현 직장 사업체 위치 시도 | 조사시점 근무지 |
| `g191p024` | P8. 현재 거주지 시도 | 실제 거주 이동 |
| `g191f006` | F2. 출신 고등학교 소재지 시도 | **부산 출신 vs 외지 출신 분리** |
| `g191majorcat` `g191dpmt` | 전공계열 / 전공 소분류 | 우리 계열 분석과 접합 |
| `직업(2018keco)_대·중·소분류` | 첫직장·현직장 직업 | **우리 KECO 직종코드와 직접 연결** |
| `g191a144` | 일의 내용 ↔ 전공 일치 정도 | "안 가는 것 아니냐" 반론 |
| `g191a126~138` | 임금·고용안정성·직무내용 만족도 | 남은 일자리의 질 |
| `g191a122` | 월평균 근로소득(만원) | 잔류 vs 유출 임금 비교 |

### 이걸로 할 수 있는 것 — 우리 논지의 마지막 조각

1. **"부산 소재 대학 졸업자의 N%가 첫 직장을 부산 밖에 잡았다"** 를 직접 말할 수 있다
2. **전공계열별 유출률** → 3차에서 "과잉 확정"된 3개 직종(연구·공학, 예술·디자인,
   교육·법률·복지)에서 실제로 유출률이 높은지 **검증**된다. 우리 구조 분석의 최종 확인이다
3. **출신고교 지역으로 분리** → *"외지 학생이 고향 간 것 아니냐"* 는 반론을 차단한다.
   부산 출신 × 부산 대학 졸업자만 따로 볼 수 있다
4. **잔류자 vs 유출자의 임금·전공일치도·만족도 비교** → 떠난 것이 합리적 선택이었는지

### 한계 (미리 밝힐 것)

- **공개분은 2005~2019.** `2019GOMS1` = 2018년 8월·2019년 2월 졸업자, 2020년 조사.
  **7년 전 코호트**다. 2020~2022년분은 마이크로데이터 별도 신청 경로
- **표본조사**다. 전국 약 1.8만 명 중 부산 소재 대학 표본이 몇 명인지 받아서 확인해야 한다.
  너무 작으면 전공계열별 분해는 못 하고 계열 묶음(그룹계열)까지만 가능
- 우리 수요 데이터는 2025~2026, GOMS는 2019. **시점 차이를 반드시 명시**하고,
  GOMS는 **"구조가 그때도 같았다"는 보강 증거**로 쓰지 **최신 수치로 쓰지 않는다**

## 3. 다운로드 — 제명이 직접 해야 하는 절차

`https://survey.keis.or.kr/goms/gomsdownload/List.jsp` → **2019GOMS1_DATA.zip**

받기 전에 **이용 설문**을 제출해야 열린다. 소속을 직접 적는 칸이 있어 본인이 해야 한다.

| 항목 | 선택 |
|---|---|
| 구분 | 개인 |
| 직업유형 | 대학(원)생 |
| 소속 | (직접 입력) |
| 활용분야 및 목적 | 연구 |

코드북은 이미 받아 뒀다 (`2019goms_code book.xlsx`, 370KB).
데이터 zip만 받아서 `raw_goms/` 에 넣으면 바로 분석 들어간다.

## 4. 이 확인이 바꾸는 것

2차 결과 문서의 주의사항이 이렇게 바뀐다.

```
(전)  "졸업자의 N%가 떠났다"고 쓰면 안 된다. 직접 연결은 GOMS 또는
      졸업자 일자리이동통계로 미룬다.

(후)  졸업자 일자리이동통계에는 지역 축이 없음을 확인했다(KOSIS 32개 표 전수).
      직접 연결은 GOMS 2019 로만 가능하며, 시점이 달라 보강 증거로만 쓴다.
      본 분석의 주 논증은 구조(배출·수요·구인배수)와 결과(순이동)의 일치이며,
      개인 단위 추적은 하지 않는다 — 이것은 한계가 아니라 설계다.
```

**마지막 문장이 중요하다.** 심사에서 "개인 추적 안 했네"가 나오면
*"공식 통계에 그 축이 없고, 있는 유일한 자료는 7년 전 것이라 보강으로만 썼다"* 가
가장 강한 답이다. 못 한 게 아니라 **확인하고 안 쓴 것**이다.
