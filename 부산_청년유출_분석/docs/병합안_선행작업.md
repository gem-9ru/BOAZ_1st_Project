# 선행 작업(부산_EDA) 병합안

폴더 정리 중에 `선행작업_부산EDA/`가 **같은 프로젝트의 이전 분석 폴더**임을 발견했다.
두 분석이 서로를 모른 채 병렬로 진행됐다. 읽어 보니 **상당 부분이 우리보다 낫다.**

---

## Ⅰ. 선행 작업이 가진 것 — 우리에게 없는 것

### 1. `N명당 대졸신입 공고 1개` — 우리 구인배수보다 정확하다 ★

```
대졸신입 공고 = 요구학력 ∈ (대학교졸, 석사이상) AND 경력요건 ∈ (무관, 신입)
N명당 1개    = 취업대상자 ÷ 대졸신입 공고
```

| 비교축 | 대졸신입 공고 | **N명당 1개** |
|---|---:|---:|
| 운송·물류 | 2 | **324명** |
| 예술·디자인·스포츠 | 31 | **90명** |
| IT·정보통신 | 29 | **54명** |
| 공학·기술·생산 | 181 | 36명 |
| 보건·의료 | 90 | 22명 |
| 경영·사무·금융·영업 | 394 | 19명 |
| 교육·복지·공공 | 312 | **3명** |

**우리 구인배수의 약점을 정면으로 피한다.** 우리는 분모가 전 연령·전 학력 `신규구직건수`라
"구직자 N명당"이라고 쓸 수 없었는데(최종감사 Ⅲ-1), 이건 **분자·분모가 모두 대졸 청년**이다.

> **구인배수를 이 지표로 교체하거나 병기해야 한다.**

### 2. 「대응 없음」 칸을 결과로 삼는 설계

선행은 양쪽이 1:1로 떨어지는 **8칸만** 지수를 내고, 짝이 없는 두 칸을 **따로 보고**한다.

```
수요 「미용·숙박·음식·경비·청소」 3,959건(16.2%)  ← 짝이 되는 대학 계열이 없다
배출 「인문·어학 + 기타」        3,222명(12.8%)  ← 짝이 되는 직종이 없다
```

우리는 인문·어학을 경영사무 0.4 / 교육복지 0.4 / 예술디자인 0.2로 **억지로 배분했다.**
선행의 지적이 맞다 — *"인문·어학은 대응 직종이 없어 0이 되고 지수가 정의상 최대가 된다."*

우리 114 시나리오는 *"배분을 바꿔도 결론이 안 바뀐다"* 를 보였지만,
**"배분하면 안 되는 칸을 배분했다"** 는 지적은 답하지 못한다.

> **"짝이 없다"는 것 자체가 발견이다.** 이 프레이밍을 가져와야 한다.

### 3. 실패 방식 2유형 — 우리 GOMS 결론과 같은 구조를 다른 데이터로

| 유형 | 특징 | 예 |
|---|---|---|
| **IT형** | 들어가기 어렵고(취업률 49.8%) 들어가면 붙는다(4차 70.1%) | 자리 자체가 없다 |
| **예술형** | 들어가긴 하는데 안 붙는다 | 디자인 4차 −18.1p · 음악 4차 **29.1%** |

**우리 4차 GOMS 결론("공학은 떠나고 예체능은 남아서 하향취업")과 같은 이분법이다.**
그런데 데이터가 완전히 다르다 — 우리는 개인 설문(GOMS), 선행은 행정통계(KEDI 유지취업률).

> **서로 다른 두 데이터가 같은 구조를 낸다. 이건 강력한 교차검증이다.**

### 4. 우리에게 아예 없던 발견 4개

| | 발견 | 숫자 |
|---|---|---|
| **1년의 벽** | 경력 요구 8,622건 중 **1년 요구가 2,787건(32.3%)** 으로 최다 | 신입을 안 받는 게 아니라 "1년만 있으면"이 벽 |
| **4년제 프리미엄 부재** | 4년제 취업률 59.4% < **전문대 71.6%** (12.2%p 낮다) | 공고 임금도 대졸 3,360 vs 전문대졸 3,318 — **차이 42만원** |
| **최저임금 밀집** | 연봉 명시분의 **22.8%가 최저임금 이하** · 최빈값 1위가 2,588만원 | 미용·돌봄은 **50.2%**, 재료·화학은 51.8% |
| **다지역 공고가 더 좋다** | 부산 확정 3,000만원 vs **다지역 4,272만원** | 최저임금 이하 22% vs **4.0%** |

**「1년의 벽」과 「4년제 프리미엄 부재」는 제안 파트에 바로 쓸 수 있다.**
최종감사에서 지적한 *"진단 9층 : 제안 1문단"* 불균형을 메울 재료다.

### 5. 성별 — 내가 "구멍"이라 한 것이 이미 있다

`out/eda_성별격차.csv` · 중계열 34종 × 취업률·유지율 성별 격차
평균 취업률 격차 **5.1%p**, 유지율 격차 5.8%p. 산업 22.3%p · 교통·운송 17.4%p가 최대.
보관 문서에 **"여성은 취업이 아니라 유지에서 밀린다"** 는 정리도 있다.

### 6. Big-데이터웨이브 6종 — 가점 대상인데 우리는 1종만 썼다 ★★

`data/데이터_목록.md`에 **"3~8이 가점 대상(Big-데이터웨이브)"** 이라고 적혀 있다.

| 확보 | 데이터 | 용도(선행 메모) |
|---|---|---|
| ✅ | 일별 행정동 **생활인구**(연령) 44,340행 | 20대 직장인구÷주거인구 → 공간 미스매치 |
| ✅ | 일별 행정동 **생활인구**(성별) 14,780행 | 성별 축 |
| ✅ | **산업단지 입주기업** 29개 산단 | 강서구 공고 최다가 산단 규모 탓인지 구인난인지 |
| ✅ | **제조업 공장등록** 11,548건 | 산단 밖 제조업 |
| ✅ | **고용 우수기업** 46개 | "좋은 일자리"의 소재 분포 |
| ✅ | 청년지원정책 109개 | **우리가 쓴 유일한 1종** |

**우리는 5차에서 "12,547건 중 쓸 만한 건 1건"이라고 썼다. 틀렸다.**
6종이 이미 확보돼 있었고 용도까지 정해져 있었다.

## Ⅱ. 우리가 가진 것 — 선행에 없는 것

| | 우리만 있는 것 | 왜 중요한가 |
|---|---|---|
| 1 | **유출 실측** (인구이동 4개년 + 20년) | 선행 README가 *"유출을 직접 못 잰다"* 고 적어 둔 부분 |
| 2 | **개인 단위 추적** (GOMS 4코호트 6,579명) | 44.6% 이탈 · 부산 출신도 31% |
| 3 | **임금 인과 분리** (통제 회귀 +14.2%) | 선발 효과 제거 |
| 4 | **지역 임금 분해** (가격 53.6% / 구성 46.4%) | "산업 구성 탓" 반론 차단 |
| 5 | **기업 규모** (300인 이상 12.2% vs 24.5%) | 원인 층 |
| 6 | **미충원 숙련 구성** (직능1수준 36.2%) | "역량 부족" 반박 |
| 7 | **인구 대비 보정** (광주 18.54 > 부산 16.05) | 비교군 |
| 8 | **114 시나리오 민감도** | 크로스워크 방어 |
| 9 | **정책 계열 분류** (양성 22 : 매칭 3) | 제안 근거 |

**선행은 「배출 ↔ 수요」까지, 우리는 「유출 → 원인 → 정책」까지다. 겹치지 않는다.**

## Ⅲ. 충돌 — 결정이 필요한 3가지

| | 쟁점 | 선행 | 우리 | 제안 |
|---|---|---|---|---|
| 1 | **배출 분모** | 취업대상자 (졸업자 − 진학·입대·유학생·제외인정) | 졸업자 | **취업대상자로 통일.** 계열별 유학생 비중이 달라(경영·경제 10.8%) 졸업자는 부푼다. 우리 3차 민감도에선 최대 0.8%p였지만 그건 전체 기준 |
| 2 | **비교축 개수** | 8칸 (짝 없는 2칸 제외) | 13계열 × 10직종 | **둘 다 쓴다.** 8칸은 지수·방어용, 13계열은 대시보드용. **단 인문·어학은 배분하지 않고 별도 표기** |
| 3 | **경쟁 지표** | N명당 대졸신입 1개 | 구인배수 | **N명당으로 교체.** 구인배수는 직종 간 상대 비교 보조로만 |

## Ⅳ. 병합 후 논리 사슬

```
① 배출 ↔ 수요의 결이 다르다          선행 8칸 지수 + 우리 13계열
   └ 짝이 없는 두 칸이 결론           선행 프레이밍 ★
② 대졸 신입 자리가 절대적으로 없다     선행 N명당 지표 ★ (4년제 24명당 1개)
   └ 게다가 「1년의 벽」              선행 ★
③ 남을 이유가 없다                   선행 (4년제 프리미엄 부재 · 최저임금 22.8%)
④ 그래서 떠났다                      우리 (순이동 · GOMS 44.6%)
⑤ 떠난 사람이 더 번다                우리 (+14.2% · 사업체 14.4%와 일치)
⑥ 왜 자리가 없나                     우리 (산업 59% · 300인이상 12.2% · 임금 89.6%)
⑦ 역량 부족이 아니다                  우리 (미충원 저숙련 36.2%)
⑧ 정책은 반대쪽에 있다                우리 (양성 22 : 매칭 3)
⑨ 공간 — 부산 안 어디인가            미착수 (생활인구·산단 데이터 보유) ★
```

**②③이 통째로 비어 있었다.** 선행을 붙이면 *"남을 이유가 없다"* 가 데이터로 선다.

## Ⅴ. 작업 순서

| | 작업 | 소요 | 효과 |
|---|---|---|---|
| **1** | **N명당 대졸신입 지표를 13계열로 재계산** | 1시간 | 구인배수 표기 오류 해소 + 지표 강화 |
| **2** | **배출 분모를 취업대상자로 통일** | 1시간 | 선행과 수치 일치 |
| **3** | **인문·어학·미용돌봄을 "짝 없음"으로 분리** | 1시간 | 프레이밍 교체 |
| **4** | 「1년의 벽」·「4년제 프리미엄 부재」 편입 | 1시간 | **제안 파트 재료** |
| **5** | 성별 축 — 선행 결과 + 우리 GOMS 결합 | 1시간 | MECE 구멍 |
| **6** | **Big-데이터웨이브 5종 활용 (공간 분석)** | 1일 | **가점 대상** |
| 7 | 문서·대시보드 수치 갱신 | 반나절 | |

**1~5는 하루면 끝난다. 6이 가점 때문에 가장 크다.**

## Ⅵ. 최종감사 수정

| 최종감사에서 쓴 것 | 실제 |
|---|---|
| "성별을 한 번도 안 봤다 — MECE 최대 구멍" | **선행에 이미 있다.** 병합만 하면 된다 |
| "Big-데이터웨이브 12,547건 중 쓸 만한 건 1건" | **6종이 이미 확보돼 있었고 가점 대상이다** |
| "심사기준 미확인" | **Big-데이터웨이브 가점이 있다는 정보가 선행에 있었다** |
| "구직자 N명당 자리 1개 표기 오류" | 선행의 **N명당 대졸신입 지표로 교체**하면 해소된다 |

> **가장 큰 교훈: 두 분석이 서로를 모른 채 굴러간 것.**
> 병합하면 분석은 강해지지만, 중복 작업에 시간을 썼다.
