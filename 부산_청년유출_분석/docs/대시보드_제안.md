# 대시보드 제안 — 무엇을, 누구를 위해, 어떻게

**아직 만들지 않았다. 방향을 정하고 만들자는 제안서다.**

---

## 1. 왜 대시보드인가 — 대회 요구사항과의 관계

대회는 *"창의적인 아이디어를 제안하거나 **데이터 기반 서비스를 기획·분석**"* 을 요구한다.
지금 우리에겐 **진단 9층**이 있고 **서비스가 없다.**

그림 6장은 **우리가 찾은 답을 보여주는 것**이고,
대시보드는 **남이 자기 질문을 던질 수 있게 하는 것**이다. 둘은 다른 물건이다.

```
그림 6장   = 우리의 결론 (정적, 설득용)
대시보드   = 남의 질문 (동적, 도구)
```

---

## 2. 핵심 결정 — 대시보드가 답할 하나의 질문

여러 지표를 늘어놓는 대시보드는 아무것도 못 한다. **하나의 질문에 답하는 도구**여야 한다.

우리 분석에서 가장 실용적인 질문은 이것이다.

> ### **"이 전공으로 부산에 남으면 어떻게 되는가?"**

이 질문은 세 사용자에게 동시에 유효하다.

| 사용자 | 이 도구로 하는 일 |
|---|---|
| **부산시 청년정책과** | 어느 계열이 가장 크게 어긋나 있는지 보고 예산 배분 근거로 삼는다 |
| **대학 진로·취업센터** | 우리 학과 학생에게 부산 노동시장의 실제 모습을 보여준다 |
| **청년 본인** | 내 전공이 부산에서 어떤 조건인지 확인한다 |

**대안으로 검토했으나 접은 것**

| 안 | 왜 접었나 |
|---|---|
| 종합 지표 모니터링 대시보드 | 지표 나열은 인사이트가 없다. 이미 부산시가 유사한 걸 운영 중 |
| 정책 시뮬레이터(예산 이동 효과) | 예산-고용 탄력성 추정치가 없다. **근거 없는 숫자를 만들게 된다** |
| 개인 맞춤 진로추천 | 개인 데이터가 없고, 추천은 우리 분석 범위 밖이다 |

## 3. 화면 구성 — 1페이지, 3층

스크롤 한 번으로 끝나는 단일 페이지. 탭 전환은 쓰지 않는다(맥락이 끊긴다).

### ■ 1층 — 진입: 상태 한 줄

```
┌──────────────────────────────────────────────────────────────┐
│  부산은 청년을 모았다가 잃는다                                 │
│                                                              │
│  20-24세        25-29세        순유출 사유 1위    구인배수     │
│   +927          −5,437          직업 74.4%        0.345       │
│  순유입          순유출          (주택 17.4%)      전국 0.406  │
└──────────────────────────────────────────────────────────────┘
```
KPI 4개 + 그림 1(연령별 순이동) 축소판. **필터 없음. 모두에게 같은 화면.**

### ■ 2층 — 핵심: 전공계열 선택기 ★ 이게 대시보드의 본체

상단에 **전공계열 13개 칩(chip) 한 줄**. 하나 고르면 아래 4칸이 동시에 바뀐다.

```
[ 경영·사무 ] [ 기계·전기전자 ] [ IT·컴퓨터 ] [ 디자인·예술 ] [ 보건·의료 ] …

┌─ 선택: IT·컴퓨터 ────────────────────────────────────────────┐
│                                                              │
│  ① 배출 vs 수요            ② 자리는 몇 개인가                │
│  ─────────────────         ─────────────────                 │
│  배출  1,917명 (5.2%)      구인배수 0.14                      │
│  수요  ███ 3.2%            구직자 7명당 자리 1개               │
│  배출  ███████ 18.9%       ● 전 직종 중 하위 2번째            │
│                                                              │
│  ③ 남으면 / 떠나면          ④ 이 계열을 겨냥한 정책            │
│  ─────────────────         ─────────────────                 │
│  이탈률      60.2%          인력 양성   6개 사업              │
│  잔류 임금   213만원        수요·매칭   1개 사업              │
│  이탈 임금   271만원 (+27%) ● 양성 편중                       │
└──────────────────────────────────────────────────────────────┘
```

**왜 전공계열이 선택축인가**
- 학생·학과·정책 모두가 **자기 것으로 인식하는 단위**다
- 우리 4개 데이터(졸업자·수요·GOMS·정책)가 **전부 이 축으로 조인된다**
- 직종을 축으로 하면 학생이 자기 위치를 못 찾는다

### ■ 3층 — 근거: 전체 지도와 방법

- 그림 3·4(전 직종 비교)를 **선택한 계열이 하이라이트된 상태**로 보여준다
- 각 수치에 **출처·시점·한계**를 툴팁으로 붙인다
- `데이터 보기`로 원자료 표를 연다
- 하단에 방법 요약 + **"우리가 틀렸던 8가지"** 링크

## 4. 상호작용 설계

| 요소 | 동작 | 이유 |
|---|---|---|
| 전공계열 칩 | 클릭 시 2·3층 동시 갱신, URL에 반영 | 링크 공유가 되어야 팀·심사위원이 특정 계열을 바로 연다 |
| 수요 채널 토글 | `공공(고용24)` ↔ `민간(크롤링)` ↔ `둘 다` | **채널 편향이 우리 발견이므로 숨기지 않고 사용자가 직접 바꿔보게** 한다 |
| 지표 호버 | 출처·시점·표본수·한계 | 모든 숫자가 어디서 왔는지 추적 가능해야 한다 |
| 유의성 표시 | 통계적으로 유의하지 않은 값은 **연하게 + "유의하지 않음"** | 공학 외 계열 임금 프리미엄을 단정하지 않기 위해 |

**의도적으로 넣지 않을 것**
- 기간 슬라이더 — 데이터 시점이 제각각이라 시계열 축이 성립하지 않는다
- 예측·추천 — 근거가 없다
- 지도(시군구) — 우리 논지는 부산 내부가 아니라 부산-수도권 간 문제다

## 6. 구현 방식 제안

| 항목 | 제안 | 이유 |
|---|---|---|
| 형태 | **단일 HTML 파일** (외부 라이브러리 없음) | 그림 6장과 같은 방식. 오프라인 열람·제출·공유가 전부 가능 |
| 차트 | 직접 작성한 SVG | 이미 만들어 둔 렌더 함수를 재사용 |
| 데이터 | JSON을 파일 안에 내장 | 서버 불필요, 파일 하나로 완결 |
| 스타일 | 그림 6장과 동일 팔레트·다크모드 | 제출물 전체가 한 세트로 보이게 |

> Tableau·Power BI도 검토했지만 **제출·공유 시 열람 환경을 통제할 수 없고**,
> 우리가 붙여야 할 한계 주석과 유의성 표시를 세밀하게 넣기 어렵다.
> 사용자가 원하면 병행 제작은 가능하다.

## 7. 만들기 전에 팀이 정해야 할 3가지

| | 결정 사항 | 선택지 |
|---|---|---|
| 1 | **전공계열 축을 무엇으로 할 것인가** | 서현 그룹계열 13종(배출 데이터 기준) ↔ GOMS 7계열(임금 데이터 기준)<br>→ **13종으로 하고 GOMS는 7계열로 매핑**하는 것을 제안 |
| 2 | **정책 칸을 넣을 것인가** | 넣으면 제안이 강해지지만 "부산시 비판"으로 읽힐 위험<br>→ **국비 비중을 같이 보여주면 구조 설명**이 된다 |
| 3 | **청년 본인을 사용자로 포함할 것인가** | 포함하면 문구를 쉽게 써야 하고, 빼면 정책 도구로 집중된다<br>→ **정책·대학 담당자를 1차 사용자**로 두는 것을 제안 |

## 9. 이 대시보드가 심사에서 하는 일

> **"진단만 하고 끝난 것 아니냐"** → 도구를 내놓는다
> **"채널 편향이 약점 아니냐"** → 토글로 직접 바꿔보게 한다. 약점을 기능으로 바꾼다
> **"숫자를 믿을 수 있나"** → 모든 수치에 출처·표본수·한계가 붙어 있다
> **"그래서 뭘 하라는 건가"** → 계열별로 양성 대 매칭 사업 수가 바로 보인다

**대시보드는 우리 분석의 요약이 아니라, 분석이 만들어낸 결과물이어야 한다.**
