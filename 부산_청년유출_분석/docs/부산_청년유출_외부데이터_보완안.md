## 1. 워크넷 구인구직통계 — 이미 받아서 열어봤다

출처: 한국고용정보원 『워크넷 구인구직 및 취업동향』 월간
`https://www.keis.or.kr/keis/ko/bbs/123/detail.do?pstSn=64756`
첨부 `(KSCO추가) 구인구직통계(YYYY.MM).xlsx` · 월별로 별도 게시물

**시트 구성 (2025.01 실물 확인)**

```
신규구인_개괄 / 신규구직_개괄 / 취업건수_개괄
구인_고용직업중분류   ← 4-1. [KECO]직업중분류 × 지역별 신규구인인원
구직_고용직업중분류   ← 5-1. 같은 축
취업_고용직업중분류   ← 6-1. 같은 축
산업별_구인
구인/구직/취업_표준직업중분류 (KSCO)
```

**핵심: 축이 `KECO 직업중분류 × 17개 시도`다.** 우리가 공고에 붙인 6자리 직종코드의
**중분류와 그대로 붙는다.** 팀 크로스워크를 새로 만들 필요가 없다.

### 이걸로 무엇이 해결되나

**① "하루 스냅샷으로 1년 수요를 말할 수 있나" → 12개월 합으로 답한다**
월별 파일 12개를 받아 합치면 부산의 **연간 신규구인인원**이 나온다.
우리 스냅샷 구성비 ≈ 워크넷 연간 구성비 이면, 스냅샷이 연간을 대표한다는 **실증**이 된다.

**② "직종 자동분류 정확한가" → 공식 통계와 분포를 맞춰본다**
건별 정확도 논쟁을 분포 일치로 대체한다.

### 실제로 맞춰봤다 (2025.01 부산, 신규구인 11,110명)

| 직종 대분류 | 워크넷 | 우리 크롤링 | 차이 |
|---|---:|---:|---:|
| 미용·여행·숙박·음식·경비·청소 | **35.4%** | 15.9% | +19.5p |
| 경영·사무·금융·보험 | 21.0% | 24.6% | −3.6p |
| 설치·정비·생산 | 17.7% | 15.9% | +1.8p |
| 교육·법률·사회복지·경찰·소방 | 8.3% | 5.8% | +2.5p |
| 연구·공학기술 | **6.4%** | 9.0% | −2.6p |
| 영업·판매·운전·운송 | 5.2% | 11.2% | −6.0p |
| 보건·의료 | **2.5%** | 13.4% | −10.9p |
| 예술·디자인·방송·스포츠 | **0.8%** | 3.5% | −2.7p |
| 건설·채굴 | 1.7% | 0.3% | +1.4p |
| 농림어업 | 1.1% | 0.3% | +0.8p |

**이 표가 이번 조사에서 가장 값진 결과다.** 두 가지를 동시에 말해준다.

**(가) 채널마다 다른 노동시장을 본다 — 이건 오류가 아니라 발견이다**
워크넷(공공 고용서비스)은 돌봄·청소가 35%, 보건·의료는 2.5%밖에 안 잡힌다.
민간 채용사이트는 반대다. **어느 한쪽만 보면 부산 일자리 구조를 틀리게 본다.**
→ "왜 공공통계 안 쓰고 크롤링했나"에 대한 답이 된다. 크롤링이 **공공통계가 못 보는
민간 채용시장을 메우는 쪽**이라고 포지셔닝하면, 우리 데이터가 약점이 아니라 기여가 된다.

**(나) 채널이 달라도 결론은 같다**
대졸이 갈 직종(연구·공학 6.4~9.0%, 예술·디자인 0.8~3.5%)은 **두 채널 모두에서 작다.**
서로 다른 편향을 가진 두 데이터가 같은 결론을 내면 그게 가장 강한 논증이다.
→ **이걸 그림 1장으로 만들자. "채널을 바꿔도 결론은 안 바뀐다".**

### 주의 3가지
- 지역 기준이 **근무지가 아니라 "구인구직을 등록한 지방노동관서"** 다. 명시할 것
- 2025년 1월 전국 신규구인이 전년 대비 **−42.7%**. 워크넷/고용24 개편 영향 가능성이 있어
  시계열 해석은 조심. **구성비만 쓰면 영향 적다** (우리 설계와 일치)
- 2025년 1월부터 KECO 분류 개정 적용. 그 이전 월과 합칠 때 확인 필요

## 2. KOSIS 국내인구이동통계 — 결과지표

- `DT_1B26003` 인구이동(성/전입지/전출지/연령별) → **부산→서울·경기 20대 순유출**
- `DT_1B26001_A01` 시군구별 이동자수 → 부산 16개 구군별
- `https://kosis.kr/`

**메우는 질문: "유출을 직접 봤나"**
우리가 원인 구조를 보여준 뒤, 결과가 실제로 그렇게 나타났음을 이 시계열로 닫는다.
전출 사유(직업·교육·주택) 항목이 있으면 **"직업" 사유 비중**을 반드시 쓸 것 —
"청년이 떠나는 건 집값 때문 아니냐"를 데이터로 차단한다.

## 3. GOMS 대졸자직업이동경로조사 — 유출 직접 증거

`https://survey.keis.or.kr/goms/gomsdownload/List.jsp` (자료받기 · zip · 신청서 작성 후 즉시)

- **공개분은 2005~2019년.** 최신분은 마이크로데이터 신청 경로 별도
- 졸업 후 **근무지 시도**를 직접 물어본다 → "부산 대학 졸업 → 어디 취업"을 **직접** 집계 가능
- 전공-직무 일치도, 일자리 만족도 문항도 있음

**메우는 질문: "일자리가 없는 게 아니라 안 가는 것 아닌가"**
전공일치도·만족도로 답한다. 다만 **2019년 자료라 최신성 공격을 받는다.**
→ 서류(9/18)에는 "본선에서 이렇게 쓰겠다"로 넣고, 본선 5주에 실제로 붙이는 게 안전하다.

## 4. 고등교육기관 졸업자 일자리이동통계 — 공식 지역이동 지표

교육부 + 국가데이터처 공동, 건강보험·국세 등 **15개 기관 DB 연계**. KOSIS 수록.
2024년 취업통계와 2023년 일자리이동통계가 2025-12-30 동시 발표됨.

- 수도권 유지취업률 83.1% vs 비수도권 80.5%
- 우리가 쓰는 2024 취업통계 원본과 **같은 조사 체계**라 접합이 자연스럽다

**할 일: KOSIS에서 시도 간 이동 세부표가 공개돼 있는지 확인.**
있으면 3번(GOMS)보다 최신이고 표본조사가 아니라 전수라서 훨씬 강하다. **확인 우선순위 높음.**

## 5. 지역별고용조사 (국가데이터처)

`https://mdis.kostat.go.kr/` · 마이크로데이터 A/B/C형
- A형: 시군코드 4자리 + 산업·직업 중분류 2자리 → **부산 × 직업중분류 × 연령** 가능
- 공표 통계로도 시도별 청년 취업자 산업·직업 특성 제공

**메우는 질문: "공고에 안 올라오는 채용은?"**
공고가 아니라 **실제 취업자 구조**라서, 공고 데이터의 커버리지 한계를 정면으로 보완한다.
신청 기간이 있어 **본선용**.

## 6. 선행연구 — 우리 차별점을 여기서 만든다

| 자료 | 무엇을 했나 | 우리와의 차이 |
|---|---|---|
| 한국은행 부산본부 『부산지역 인구이동에 대한 분석, 청년층을 중심으로』 (2019.11) | 인구이동 통계로 청년 순유출 분해 | **인구 쪽만. 일자리 수요 구조가 없다** |
| 『부산광역시 대학 졸업자의 취업이동 특성과 결정요인 분석』 (RISS) | 졸업자 취업이동 결정요인 | **개인 속성 중심. 직종별 수요 구조가 없다** |
| 『청년층 인재유출 결정요인 분석과 정책과제: 부산지역』 (KCI) | 유출 결정요인 회귀 | 마찬가지 |
| 부산연구원 『부산청년패널조사로 본 청년 노동실태』 (2024) | 청년 만족도·정책 | **수요 측(기업 공고)이 없다** |

**우리 자리가 여기 있다.**
선행연구는 전부 **사람 쪽(누가·왜 떠나는가)** 을 봤다.
우리는 **일자리 쪽(부산에 어떤 일이 남아 있는가)** 을 25,135건 실물 공고로 본다.
→ 기획서 한 줄: **"떠나는 사람이 아니라, 남아 있는 일자리를 본다."**

## 7. 심사 질문 → 보완 설계 (방어가 아니라 제거)

| 예상 질문 | 기존 답(방어) | **보완 설계(제거)** |
|---|---|---|
| 하루 공고로 1년 수요를? | 구성비만 씀 | **워크넷 12개월 합과 구성비 일치 검증** → 대표성을 실증 |
| 직종 자동분류 정확한가? | 대분류 98% | **공식 통계와 분포 대조표 제시** → 검증 완료된 분류로 격상 |
| 왜 공공통계 아닌 크롤링? | (답 없었음) | **채널 편향 비교표** → 크롤링이 공공이 못 보는 시장을 메움을 증명 |
| 유출을 직접 봤나? | 원인까지만 | **KOSIS 순유출 + 전출사유 "직업"** + 본선 GOMS 근무지 |
| 일자리가 없는 게 아니라 안 가는 것? | L1 질 분석 | **GOMS 전공일치도·만족도**로 "갈 만한 일이 아니다"를 응답자 입으로 |
| 집값·주거 때문 아닌가? | (답 없었음) | **전출사유 분해**로 직업 사유 비중 제시 |
| 이미 다 나온 얘기 아닌가? | (답 없었음) | **선행연구 표 + "수요 측을 실물 공고로 본 연구는 없다"** |

## 9. 그림 구성 수정 (5장 → 6장)

1. **엇갈린 결** — 학과 배출% ↔ 직종 수요% 발산형 막대 *(메인)*
2. **채널을 바꿔도 결론은 같다** — 워크넷 vs 크롤링 vs 졸업자 3열 비교 *(신규·방어력 최고)*
3. **과잉/과소 지도** — LQ 버블
4. **남은 일자리의 질** — 연봉중앙값 × 대졸요구율 산점도
5. **못 붙어 있다** — 과잉 계열의 유지취업률
6. **결과** — 부산 20대 순유출 시계열 + 전출사유 중 "직업" 비중

## 10. 남은 리스크

- **IT 과소추정**: 워크넷에서도 정보통신 연구개발·공학기술직 부산 24명(0.2%)으로 극소. 두 채널이 같은 방향이라 리스크는 줄었지만, 부산 IT 채용이 **수도권 본사 공고로 올라가** 양쪽에서 안 잡힐 가능성은 남는다. 원티드·점핏 표본으로 한 번 더 확인.
- **GOMS 최신성**: 2019년. 4번(일자리이동통계)이 되면 3번은 보조로 내린다.
- **워크넷 지역 기준**: 근무지가 아니라 등록 관서. 각주 필수.
