# 부산 청년 유출 EDA — 전 과정 정리

주제 **인재 배출과 기업 수요의 엇갈린 결: 부산 지역 청년 유출 원인 분석**

---

## 1. 큰 질문

> **부산은 왜 청년을 잃는가? 그것이 일자리 때문인가?**

이 질문을 데이터로 답하려면 세 가지를 각각 증명해야 했다.

| | 물어야 할 것 | 어떤 데이터가 필요한가 |
|---|---|---|
| A | 실제로 청년이 나갔는가 | 인구이동 |
| B | 그 이유가 일자리인가 | 이동 사유 · 개인 추적 |
| C | 왜 일자리가 없는가 | 노동수요 구조 · 산업 |

시작 시점에 우리에게 있던 것은 **C의 재료뿐**이었다(채용공고·졸업자 통계).
A와 B는 외부 데이터를 붙여 채웠다.

## 2. 답을 찾아간 경로 (7단계)

| 단계 | 한 일 | 얻은 답 |
|---|---|---|

| **2차** | 국내인구이동통계 4개년 | 20-24세 **+927 → 25-29세 −5,437**, 사유의 **74.4%가 직업** |
| **3차** | 임의 선택 3개를 전수로 뒤집음 (114 시나리오) | 크로스워크·학제는 결론을 못 흔든다. **단 배율 주장은 깨진다** |
| **4차** | GOMS 개인 데이터로 직접 추적 | 부산 대학 졸업자 **44.6%가 부산 밖**에 첫 자리 |
| **5차** | 고용24 산업·임금 축, 전국사업체조사 | 부산 수요의 **59%가 보건복지·제조**, 정보통신은 서울의 1/3 |
| **6차** | 인구 대비 보정 | 순유출률 1위는 **광주**. 부산은 2위. 그러나 **모았다가 잃는** 곳은 부산뿐 |
| **7차** | 임금 회귀에 개인 특성 통제 | 격차의 1/3은 선발, **2/3(+14.2%)는 남는다** |

## 4. 무엇을 어떻게 보정했나

| 문제 | 어떻게 처리했나 |
|---|---|
| **단위 불일치**<br>졸업자=1년 flow / 공고=하루 stock / 구인=12개월 | 절대수 비교 금지. **모든 비교를 구성비(%)로** 통일 |
| **학과 ↔ 직종을 잇는 기준이 없음** | 중계열 → 직종대분류 **가중 크로스워크**를 만들고, 조인은 라벨이 아니라 **6자리 직종코드**로 |
| **채널 편향**<br>공공(고용24)과 민간(크롤링)이 정반대 | 숨기지 않고 **두 채널을 나란히 보고**. 돌봄·청소 44.9% vs 15.9%, 보건·의료 2.8% vs 13.4% |
| **GOMS 첫직장 문항이 이직자 위주**(커버리지 27%) | 첫직장 없으면 현직장으로 대체 → **78.4%**. 커버리지 100%인 현재 거주지로 교차 검증 |
| **직종코드 체계 불일치**<br>GOMS는 1~10, 우리는 0~9 | −1 보정. 안 했으면 표 전체가 한 칸씩 밀렸다 |
| **인구 규모 차이** | 순유출을 20대 인구로 나눠 **‰(1천명당)** 로 재계산 |
| **선발 편향**<br>더 우수한 사람이 떠난 것 아닌가 | 성별·학교유형·설립·전공·졸업평점·어학연수·부모소득 **단계적 통제 회귀** |
| **예산 단위 불명**<br>청년정책 `예산(천원)` 값이 안 맞음 | 원문 시행계획 PDF와 대조 → **실제 단위는 백만원**(헤더 오류). 공식 수치로 인용 |

## 5. 틀렸거나 좁혀야 했던 것 (8개)

작은 가설들은 자주 틀렸다. **틀린 것을 먼저 공개하는 쪽이 방어에 유리하다.**

| 처음 주장 | 검증 결과 | 지금 쓰는 문장 |
|---|---|---|
| "대졸 직종을 **3.41배 과잉 배출**" | 분자는 대졸자만, 분모는 전 학력 수요 → 정의 바꾸면 **0.84~3.95배**로 요동 | **배율 주장 폐기.** "구성이 다르다"까지만 |
| "부산 일자리의 **67.5%**가 대졸 무관 직종" | 공공 채널 기준. 민간 기준은 **32.4%** | 출처를 문장 안에 넣어 서술 |
| "채널을 바꿔도 결론 불변" | 경영·사무·보건의료는 채널 따라 **부호가 뒤집힘** | **대졸 직종(연구공학·예술디자인)에 한해** 유지 |
| "대기업 본사 부재가 원인" | 사업체당 평균 종사자 부산 **3.90명 = 경기**, 전국 4.05명 | **가설 기각.** 원인은 크기가 아니라 **산업 구성** |
| "자리가 적으니 떠난다" | 이탈률 ~ 구인배수 상관이 **4가지 집계 전부 유의하지 않음**(7대계열 Spearman +0.679 p=.094 / Pearson +0.313 p=.495 / 11계열 Spearman +0.227 p=.502 / Pearson +0.252 p=.455) → **양으로는 설명 불가**(귀무). 「반대」로 단정하면 안 됨 | 양이 아니라 **임금**이 움직인다 |
| "**7개 계열 전부** 이탈자 임금 우위" | 통제하면 **공학만 유의**(+23.7%), 나머지는 우연과 구분 안 됨 | **떠나서 이득 있는 전공만 떠난다** |
| "25-29세 순유출 **전국 1위** = 가장 심각" | 인구 보정하면 **광주 18.54‰ > 부산 16.05‰**. 20대 전체로는 경북(40.07‰)의 1/3 | **"가장 많이 잃는 곳"이 아니라 "모았다가 잃는 유일한 곳"** |
| "졸업자 일자리이동통계로 추적하자" | KOSIS 32개 표 전수 확인 — **지역 축이 없다**(직장 이동일 뿐) | 경로 폐쇄. GOMS로 대체 |

## 6. 결론

### 한 문장

> **부산은 청년을 가장 많이 잃는 도시가 아니다. 모았다가 잃는 유일한 도시다.**

### 근거 4층

**① 나갔다 — 그것도 부산만의 모양으로**
20-24세 **+927** 순유입 → 25-29세 **−5,437** 순유출. 전환폭 −6,364로 2위(대전)의 **3.5배**.
**20-24세가 순유입인 비수도권 광역시는 부산뿐이다.**
광주·경북·경남은 20대 초반부터 계속 나가고, 서울·대전은 내내 들어온다. **부산만 모았다가 놓친다.**
(순유출률 자체는 광주 18.54‰ > 부산 16.05‰ — 부산은 가장 많이 잃는 곳이 **아니다.**)
20년 누적 부산→수도권 청년 순유출 **186,499명**(연간 졸업자의 5배).

**② 이유는 직업이다**
순유출 사유의 **74.4%가 직업**, 주택은 17.4%. **교육은 +3,479 순유입**.
나간 사람의 **80.5%가 수도권**으로 갔다.

**③ 떠난 사람은 실제로 더 번다 — 단, 공학만**
부산 대학 졸업자 **44.6%가 부산 밖**에 첫 자리. 부산 출신도 **31%** 떠났다(귀향 효과로 설명 안 됨).
개인 특성 통제 후에도 이탈자가 **+14.2% 더 번다**(t=4.22).
계열별로는 **공학 +23.7%만 유의**하고 의약은 +1.1%(이탈률도 최저 32.5%).

**④ 부산에 남은 일자리의 결이 다르다**
부산 노동수요의 **59.1%가 보건복지·제조** 두 산업. 정보통신업 구인 비중은 **서울의 1/3**.
월 100만원 미만 구인이 **21.1%**(서울 12.6%).
구인배수는 예술·디자인 **0.06**, 연구·공학 **0.14** — 대졸이 가는 직종일수록 낮다.

### 그래서 무엇을 말할 것인가

```
공학    → 떠난다        (이탈 60.2%, 떠나면 +23.7%)
예체능  → 못 떠난다      (떠나도 +4%, 남아서 월 176.9만원)
의약    → 안 떠난다      (부산에서도 같은 돈, 이탈 32.5%)
```

**미스매치는 유출로만 나타나지 않는다. 하향취업으로도 나타난다.** 같은 원인의 다른 출구다.

그리고 **정책은 반대쪽에 있다.** 2025년 부산 청년정책 **95개 사업 4,146억원** 중
**교육(인력 양성)이 57.5%, 일자리는 13.0%**다.
대졸 직종 관련 16개 사업 중 **14개가 "인력 양성"(배출을 늘림)**, 수요·매칭은 **2개**다.

> **부산의 문제는 배출이 아니라 수요인데, 정책은 배출을 더 늘리는 쪽에 14:2로 몰려 있다.**

## 7. 시점 정렬

크롤링은 2026-09-07, 나머지는 2018~2026에 흩어져 있다. **합치거나 평균 내지 않는다.**
각 데이터가 다른 질문에 답하고, 모든 비교를 구성비로 해서 시점 차이를 흡수한다.
부산 25-29세 순유출이 4년간 **3.2% 안**에서 움직인 것이 "구조는 안 변한다"의 근거다.
가장 약한 고리는 **GOMS 2019**(7년 차이)이며, 최신 수치가 아니라 **메커니즘 보강**으로만 쓴다.
