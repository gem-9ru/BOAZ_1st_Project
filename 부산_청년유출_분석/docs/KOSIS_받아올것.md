# KOSIS에서 받아올 것 (4개)

로그인 후 아래 주소로 바로 가면 해당 통계표가 열린다.
**공통 절차**는 맨 아래에 한 번만 적었다. 파일은 `raw_industry/` 에 넣으면 된다.

---

## ① 시도·산업·규모별 임금  ★최우선

```
https://kosis.kr/statHtml/statHtml.do?orgId=118&tblId=DT_118N_MON061
```
사업체노동력조사 · 근로실태부문 · 상용근로자 1인이상

| 설정 | 무엇을 고르나 |
|---|---|
| **항목** | `월평균 임금총액` (또는 월급여액) — 하나면 충분. 근로시간도 있으면 좋음 |
| **행정구역(시도)** | **전체 선택** (전국 포함 18개) |
| **산업분류** | **대분류만** (중분류까지 가면 파일이 너무 커짐) |
| **규모** | **전체 구간** (5-9인, 10-29인, 30-99인, 100-299인, 300인이상 …) |
| **시점** | **2024년** 1개면 충분 (여유되면 2022~2024) |

> **이 표가 "부산 임금이 낮은가"를 직접 답한다.**
> 같은 산업·같은 규모 칸에서 부산과 서울을 비교하면 구성 효과가 빠지고 순수 지역 격차만 남는다.

## ② 시도·산업·종사자규모별 사업체수·종사자수  ★최우선

```
https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1K52F03
```
전국사업체조사 · 등록기반 11차개정(2020~)

| 설정 | 무엇을 고르나 |
|---|---|
| **항목** | `사업체수`, `종사자수` 둘 다 |
| **시도** | **전체 선택** |
| **산업분류** | **`계`(전산업)만이라도 OK.** 대분류까지 되면 더 좋음 |
| **종사자규모** | **전체 구간** ← **이게 핵심. 300인 이상 구간이 반드시 포함돼야 함** |
| **시점** | **2024년** |

> **"부산에 큰 회사가 없다"는 가설을 정확히 확인하는 표다.**
> 지금은 사업체당 평균 종사자(부산 3.90명 = 경기)로만 봤는데, 평균은 대기업 유무에 둔하다.
> **300인 이상 사업체의 종사자 비중**을 부산·서울·전국에서 비교해야 답이 나온다.

## ③ 시도·산업별 고용 (빈 일자리 수)  ○보너스

```
https://kosis.kr/statHtml/statHtml.do?orgId=118&tblId=DT_118N_MOND66
```
사업체노동력조사 · 고용부문

| 설정 | 무엇을 고르나 |
|---|---|
| **항목** | `빈 일자리 수` **필수**, 있으면 `종사자수`·`채용인원`도 |
| **시도** | 전체 |
| **산업** | 대분류 |
| **시점** | 2025년 월별 또는 2024~2025 |

> 빈 일자리 = 지금 사람을 뽑고 있는데 못 채운 자리.
> **부산의 대졸 친화 산업에서 빈 일자리가 적다면 "수요 부족"이 확정된다.**

## ④ 미충원 사유 (직종별)  ○보너스

```
https://kosis.kr/statHtml/statHtml.do?orgId=118&tblId=DT_118N_DEN068
```
직종별사업체노동력조사 · 미충원 사유 · 직종별·규모별·직능수준별 (2024 상반기)

| 설정 | 무엇을 고르나 |
|---|---|
| **항목** | 미충원 사유 전체 (임금조건, 근로조건, 경력자 부족, 자격 부족 등) |
| **직종** | 전체 |
| **시점** | 최근 |

> **이게 "역량 부족이냐 조건 문제냐" 논쟁을 끝낸다.**
> 기업이 직접 답한 미충원 사유가 `임금·근로조건`이면 역량 문제가 아니고,
> `자격·경력 부족`이면 역량 문제다.
> ⚠ **시도 구분이 없을 수 있다**(전국 표본 조사). 지역 축이 없으면 전국 벤치마크로만 쓴다.
> 열어보고 시도 항목이 없으면 **그냥 넘어가도 된다.**

# 공통 절차

1. **로그인** → 위 주소로 이동
2. 화면 왼쪽 위 **`조회설정`** (또는 `+ 설정`) 클릭
3. 팝업에서 **항목 / 분류(시도·산업·규모) / 시점** 을 위 표대로 체크
   - **기본 화면은 일부만 보여준다. 반드시 `전체선택`을 눌러야 한다**
   - 분류가 여러 개면 탭으로 나뉘어 있으니 탭마다 선택
4. `조회` 누르고 표가 제대로 나오는지 확인
5. 오른쪽 위 **`다운로드`** → 파일형태 **`CSV`** 또는 **`EXCEL(xlsx)`** → 받기
   - `행렬전환`·`코드포함` 옵션은 **건드리지 말 것** (기본값 그대로)

## 받은 파일이 이렇게 생겼으면 성공

**①번** — 행에 시도·산업·규모가 있고 값이 임금(원 단위 6자리 수)
```
행정구역(시도)  산업분류      규모        2024
부산광역시      제조업        300인이상    4,120,000
부산광역시      제조업        30-99인      3,240,000
서울특별시      제조업        300인이상    5,010,000
```

**②번** — 규모 구간에 `300~499명`, `500명 이상` 같은 항목이 보여야 함
```
시도        산업   종사자규모      사업체수    종사자수
부산광역시   계     300~499명       xxx        xxx
부산광역시   계     500명 이상      xxx        xxx
```

## 잘 안 될 때

- **셀 수 초과 경고** → 시점을 1개 연도로 줄이거나 산업을 `계`로 줄인다
- **다운로드가 안 열림** → 팝업 차단 해제
- **CSV 글자가 깨짐** → 그냥 보내면 된다(인코딩은 이쪽에서 처리)
- **항목 이름이 위 표와 조금 달라도** 의미가 같으면 그대로 진행

**①②만 있으면 충분하다. ③④는 시간 남으면.**
