# 부산 청년 유출 분석 — 브리핑

> 이 문서 하나로 전체 설명이 된다.
> **중심은 시각화가 아니라 논리 과정이다.** 시각화는 6절과 부록에 있다.

---

## 0. 결론 먼저

> ### 부산은 청년을 가장 많이 잃는 도시가 아니다. **모았다가 잃는 유일한 도시**다.
> ### 이유는 집값도 대학의 실패도 아니라 **일자리의 결**이다.

```
20-24세  +927   들어온다        ← 대학이 불러들인다
25-29세  −5,437 나간다          ← 일자리가 못 받아낸다
순유출 사유의 74.4%가 "직업"     ← 주택은 17.4%
```

---

## 1. 출발점 — 주제를 검증 가능한 형태로 바꿨다

주제는 **"인재 배출과 기업 수요의 엇갈린 결"** 이다. 이 말을 그대로는 검증할 수 없어서
**세 개의 독립된 질문**으로 쪼갰다. 셋 다 증명돼야 주제가 성립한다.

| | 물어야 할 것 | 필요한 데이터 | 시작 시점 보유 |
|---|---|---|---|
| ① | 청년이 실제로 나갔는가 | 인구이동 | ✗ |
| ② | 그 이유가 일자리인가 | 이동 사유 · 개인 추적 | ✗ |
| ③ | 왜 일자리가 없는가 | 노동수요 구조 | **○ (채용공고·졸업자통계)** |

**우리가 가진 것은 ③의 재료뿐이었다.** 이 사실을 먼저 인정한 것이 전체 설계의 출발점이다.
그래서 외부 데이터 6종을 붙이게 됐고, 그 순서가 아래의 논리 사슬이다.

---

## 2. 논리 사슬 — 각 단계는 앞 단계가 **강제**했다

> 이 절이 이 문서의 본체다. **답이 나올 때마다 새 의문이 생겼고, 그 의문이 다음 데이터를 불렀다.**

### 1단계 · 배출과 수요를 비교하려 했더니 축이 안 맞았다

| | |
|---|---|
| **하려던 것** | 부산 대학이 배출하는 인력과 부산 기업이 찾는 인력의 구성 비교 |
| **막힌 지점** | 졸업자는 **학과** 축, 공고는 **직종** 축 — 그대로는 못 붙인다 |
| **판단** | 중계열 → 직종대분류 **가중 크로스워크**를 직접 제작. 조인은 **라벨이 아니라 6자리 코드**로 |
| **또 하나** | 졸업자는 1년 flow, 공고는 하루 stock — **단위가 다르다.** 절대수를 버리고 **구성비만** 쓰기로 |
| **결과** | 배출과 수요의 직종 구성이 다르다 |

### 2단계 · "구성이 다르다"는 유출의 증거가 아니었다

| | |
|---|---|
| **생긴 의문** | 구성이 다른 게 정말 청년이 떠나는 것으로 이어지나? |
| **확인한 것** | 취업통계 **94개 컬럼 어디에도 취업 지역이 없다** → 우리 데이터로는 유출을 못 본다 |
| **그래서** | 국내인구이동통계(외부)를 붙임 |
| **결과** | 20-24세 **+927** → 25-29세 **−5,437** · 순유출 사유의 **74.4%가 직업** |

→ **이 단계에서 "집값 때문 아니냐"는 반론이 데이터로 닫혔다.**

### 3단계 · 크로스워크는 우리가 만든 것이라 의심스러웠다

| | |
|---|---|
| **생긴 의문** | 학과를 다르게 배분하면 결론이 바뀌지 않나? |
| **한 일** | 크로스워크 배분 19 × 학제 3 × 수요정의 2 = **114개 시나리오 전수** |
| **결과** | 114/114에서 부호 유지 — **크로스워크는 결론을 못 흔든다** |
| **동시에 발견** | **"3.41배 과잉 배출"은 못 버틴다.** 수요 정의를 넓히면 0.84~3.95배로 요동 |
| **그래서** | **배율 주장을 폐기**하고 "구성이 다르다"는 서술까지만 쓰기로 |

→ 검증하려던 것이 아니라 **주장을 스스로 깎은 단계**다.

### 4단계 · 순이동은 졸업자 추적이 아니었다

| | |
|---|---|
| **생긴 의문** | −5,437 안에 부산 대학 졸업자가 몇 명인지 모른다 |
| **찾아본 것** | 졸업자 일자리이동통계 — **KOSIS 32개 표 전수 확인 결과 지역 축이 없다** (직장 이동일 뿐) |
| **그래서** | GOMS(개인 설문)로 대체 |
| **보정 두 가지** | ⑴ 첫직장 문항 커버리지 27% → 현직장으로 메워 **78.4%**<br>⑵ 4개 코호트(2016~19) 풀링 → 부산 표본 1,557 → **6,579명** |
| **결과** | 부산 대학 졸업자 **44.6%가 부산 밖**에 첫 자리. **부산 출신도 31% 떠났다** |

→ "외지 학생이 고향 간 것 아니냐"가 여기서 닫혔다.

### 5단계 · 현상만 나열하고 원인이 없었다

| | |
|---|---|
| **생긴 의문** | 왜 부산에 그런 일자리가 없나? 지금까지는 현상 → 현상 → 현상이다 |
| **한 일** | 고용24 산업·임금 축 + 전국사업체조사 |
| **결과** | 부산 노동수요의 **59%가 보건복지·제조** 두 산업 · 정보통신업은 서울의 1/3 |
| **이때 기각한 가설** | "대기업이 없어서다" — 사업체당 평균 종사자가 부산 3.90 = 경기 3.90 |

→ **이 기각은 8단계에서 뒤집힌다.** 지표를 잘못 골랐던 것이다.

### 6단계 · 비교군이 없었다

| | |
|---|---|
| **생긴 의문** | "부산 문제"라고 하려면 다른 지역과 비교해야 한다. 안 했다 |
| **한 일** | 17개 시도 연령별 순이동을 **20대 인구로 나눠** 순유출률 계산 |
| **결과** | **순유출률 1위는 광주(18.54‰), 부산은 2위(16.05‰)** |
| **그런데** | **20-24세가 순유입인 비수도권 광역시는 부산뿐** · 전환폭 −6,364는 2위의 3.5배 |
| **그래서** | 주장을 **"양"에서 "모양"으로 전환** — *"가장 많이 잃는 곳"이 아니라 "모았다가 잃는 유일한 곳"* |

→ **주장이 깨진 게 아니라 더 단단해진 단계.** 절대수 1위는 규모 효과로 반박당하지만
전환 패턴은 인구 규모와 무관하다.

### 7단계 · 떠난 사람이 더 번다 — 원래 우수한 사람 아니었나

| | |
|---|---|
| **생긴 의문** | 임금 격차가 지역 효과인가, **더 우수한 사람이 떠난 것**(선발 효과)인가 |
| **한 일** | 성별·학교유형·설립·전공·졸업평점·어학연수·부모소득·코호트를 **단계적으로 통제한 가중 OLS** |
| **결과** | 원시 +21.1% → 통제 후 **+14.2% (t=4.22)**. 격차의 1/3은 선발, **2/3는 남는다** |
| **동시에 수정** | 계열별로 보면 **일부만 유의**하다 → 4단계의 "전 계열 임금 우위"를 좁힘 |

### 8단계 · "부산 임금이 낮은 건 산업 구성 탓" 반론

| | |
|---|---|
| **생긴 의문** | 부산에 저임금 산업이 많아서 평균이 낮은 것 아닌가 |
| **한 일** | 같은 **산업 × 같은 규모** 칸에서 부산 vs 서울 비교 후 구성/가격 효과 분해 |
| **결과** | 30개 칸 중 **26칸에서 부산이 낮다**(칸 평균 89.6%) · 격차의 **53.6%가 가격 효과** |
| **가설 부활** | 300인 이상 사업체 종사자 비중 **부산 12.2% vs 서울 24.5%** → **5단계의 기각을 철회** |
| **교차 검증** | 사업체 단위 격차 **14.4%** ≈ GOMS 개인 격차 **14.2%** — 다른 조사가 같은 값 |

### 9단계 · 정책이 양성에 몰렸다면 역량 부족이란 뜻 아닌가

| | |
|---|---|
| **생긴 의문** | 예산 57.6%가 인력 양성이면 부산시는 "역량 부족"으로 진단한 것 아닌가 |
| **한 일** | 직능수준별 미충원 + 빈일자리율 확인 |
| **결과** | 부산 미충원의 **36.2%가 직능1수준**(전국 19.9%), **직능4수준은 0.5%**(전국 2.5%) |
| **결론** | **부산이 못 채우는 자리는 저숙련이다. 고숙련 미충원은 전국보다 적다** |
| **결정적 논리** | 역량 부족이면 **떠나서 더 벌 이유가 없다.** 기계·전기전자는 떠나면 +25.6% |


### 10단계 · 선행 작업과 병렬로 굴러가고 있었다

| | |
|---|---|
| **발견** | 폴더 정리 중 `선행작업_부산EDA/`가 같은 프로젝트의 이전 분석 폴더임을 확인 |
| **읽어 보니** | ⑴ 우리보다 나은 경쟁 지표(**N명당 대졸신입 1개**) ⑵ 성별 분석 이미 존재<br>⑶ **Big-데이터웨이브 6종 확보** — 가점 대상인데 우리는 1종만 썼다 |
| **한 일** | 선행 발견 4개를 우리 데이터로 **재계산해 검증**하고 13계열로 편입 |
| **결과** | 「1년의 벽」 32.3% · 4년제 프리미엄 연 40만원 · 최저임금 22.8% · 다지역 공고 +1,200만원 |
| **성별** | 여성은 취업이 아니라 **유지에서 밀리고**(유지 격차 +6.5%p), 남으면 **월 49만원 덜 받는다** |

→ **「남을 이유가 없다」는 층이 통째로 비어 있었고 여기서 채워졌다.**

### 11단계 · 부산 안에서는 어디인가 — 공간 축

| | |
|---|---|
| **생긴 의문** | 「부산에 자리가 없다」는 부산 전체 이야기다. 안에서는 어떻게 갈리나 |
| **한 일** | Big-데이터웨이브 생활인구·산단·공장등록·고용우수기업 5종 활용 |
| **교차검증** | 기지국 신호(생활인구)와 크롤링 공고가 **스피어만 +0.68**로 같은 지도를 그린다 |
| **결과** | 청년 1만명당 대졸신입 **강서구 281.6 ↔ 서구 22.0 (13배)**<br>184개 동 중 「일하러 오는」 동은 **4개**<br>일자리 최다 강서구는 **남성 유입비가 여성의 2배**(산단 고용 6.2만) |
| **그 일자리의 정체** | 제조업 공장 11,548개 중 조선·금속가공 **28.9%**, 전자·정밀·바이오 **1.4%** |

## 3. 전 과정을 관통한 방법 원칙 3가지

| | 원칙 | 왜 |
|---|---|---|
| 1 | **절대수 금지, 구성비만** | 단위가 다르다(연간/12개월/하루). 이것이 **시점 차이 2016~2026도 흡수**한다 |
| 2 | **채널을 숨기지 않고 둘 다 보고** | 공공(고용24)과 민간(크롤링)은 돌봄·청소가 44.9% vs 15.9%로 정반대.<br>**편향 방향이 반대인 두 데이터가 같은 결론을 내는 것**이 우리 방어선 |
| 3 | **임의 선택은 전수로 뒤집기** | 114 시나리오. 덕분에 논쟁을 끝냈고, 동시에 **못 버틸 주장도 찾아냈다** |

**시점이 흩어진 것은 문제가 아니다.** 각 데이터가 *다른 질문*에 답하므로 합치거나 평균 내지 않는다.
실제로 부산 25-29세 순유출은 4년간 **3.2% 안**에서 움직였다 — 구조라는 근거이자
1~2년 시점 차가 결론을 안 바꾼다는 근거다.

## 5. 결과 요약

**① 나갔다 — 부산만의 모양으로**
20-24세 +927 → 25-29세 −5,437. 전환폭 −6,364 = 2위(대전)의 3.5배.
20년 누적 부산→수도권 청년 순유출 **186,499명** = 연간 졸업자의 5배.

**② 이유는 직업이다**
순유출 사유의 **74.4%가 직업**, 주택 17.4%, 교육은 +3,479 순유입. 나간 사람의 80.5%가 수도권행.

**③ 떠난 사람이 실제로 더 번다**
졸업자 44.6%가 부산 밖, 부산 출신도 31%. 개인 특성 통제 후에도 **+14.2%**.
사업체 통계의 부산-서울 임금 격차 **14.4%** 와 일치.

**④ 남은 일자리의 결이 다르다**
부산 수요의 59%가 보건복지·제조. 정보통신업 종사자 서울의 3.9%.
300인 이상 사업체 종사자 비중 12.2%(서울 24.5%). 같은 산업·규모에서도 임금이 89.6% 수준.

**⑤ 정책은 반대쪽에 있다**
계열 명시 32개 사업 중 **양성 22 : 매칭 3**. 예산은 교육 57.6% : 일자리 12.8%.
단 **교육 예산의 77.1%가 국비** — 부산시 진단이라기보다 중앙 공모사업 구조의 결과.

**⑥ 남을 이유 자체가 없다** (선행 병합)
「1년의 벽」 — 경력 요구 8,622건 중 **1년 요구가 32.3%**로 최다. 그런데 대졸 신입 자리는 1,070건.
4년제는 전문대보다 취업률이 **9.9%p 낮고** 공고 임금 차이는 **연 40만원**.
남은 자리의 **22.8%가 최저임금선**이고, 부산에 묶이지 않은 공고는 연봉이 **1,200만원 높다**.

**⑦ 성별로 쪼개면 두 개의 다른 문제다**
남성은 **떠나고**(이탈 42~58%), 여성은 **남아서 월 49만원 덜 받는다**.
여성은 취업이 아니라 **유지에서 밀린다**(유지 격차 +6.5%p). 디자인·예술 여성 잔류자는 **월 155만원**.

**⑧ 부산 안에서도 어긋나 있다**
청년 1만명당 대졸신입 **강서구 281.6 ↔ 서구 22.0(13배)**, 청년 최다 거주 부산진구는 31.0으로 평균 이하.
184개 행정동 중 청년이 「일하러 오는」 곳은 **4개**뿐이다.
일자리가 가장 많은 강서구는 **남성 유입비가 여성의 2배**이고, 그 일자리는 조선기자재·금속가공이다.

### 계열마다 나타나는 방식이 다르다
```
기계·전기전자 / 물류·운송  →  떠난다      (이탈 56~58%, 떠나면 +26%)
IT·컴퓨터                →  수도권으로   (수도권행 24.6% 1위 — 부산에 산업이 없다)
디자인·예술              →  못 떠난다    (떠나도 +5%, 남아서 월 175만원)
보건·의료                →  안 떠난다    (부산에서도 같은 돈)
```
**미스매치는 유출로만 나타나지 않는다. 하향취업으로도 나타난다.**

## 8. 대시보드 — 분석 질문과 도출 인사이트

첨부 HTML은 **최종 산출물이 아니라 설계 시안**이다. 최종은 Tableau로 만든다.

### 이 대시보드가 답하는 하나의 질문

> ### **"이 전공으로 부산에 남으면 어떻게 되는가?"**

현황판이 아니다. **선택 → 비교 → 판단**의 도구다.
지표를 늘어놓지 않고 한 질문에만 답하도록 설계했고, 그래서 **써야만 보이는 것**이 생긴다.

| 사용자 | 이 도구로 하는 일 |
|---|---|
| **청년** (1차) | 내 전공이 부산에서 어떤 조건인지 확인한다 |
| **정책 담당자** (2차) | 청년이 마주하는 현실을 계열별로 보고 예산 배분 근거로 삼는다 |

### 도출 인사이트 ① — 유출과 하향취업은 같은 원인의 다른 출구다

칩을 **기계·전기전자 → 디자인·예술**로 바꾸면 드러난다.

| | 배출% | 공공수요% | 이탈률 | 잔류자 월소득 | 임금 프리미엄 |
|---|---:|---:|---:|---:|---:|
| 기계·전기전자 | 13.6 | 11.0 | **56.0%** | 211만원 | **+25.6%** (뚜렷) |
| 디자인·예술 | 12.1 | **0.8** | 37.7% | **175만원** | +5.5% (뚜렷하지 않음) |

**둘 다 배출이 수요보다 많은데 행동이 정반대다.**
디자인·예술은 수요가 0.8%로 훨씬 열악한데 **덜 떠난다.**
갈림길은 **떠나서 얻을 것이 있느냐**다. 기계는 +25.6%라 떠나고, 디자인은 +5.5%라 남는다.
그리고 **남은 대가가 월 175만원** — 전 계열 최저다.

> **미스매치는 유출로만 나타나지 않는다. 하향취업으로도 나타난다.**
> 한 계열만 봐서는 안 보이고, **두 계열을 번갈아 눌러야 보인다.**

### 도출 인사이트 ② — 정책은 "떠나는 계열"이 아니라 "산업 육성 정책이 있는 계열"에 붙어 있다

4층을 **이탈률 내림차순**으로 정렬하면 어긋남이 한눈에 보인다.

```
이탈률 1위  물류·운송      57.6%   양성 1 : 매칭 1
이탈률 2위  기계·전기전자   56.0%   양성 7 : 매칭 0   ← 반도체·조선·기술사관
이탈률 3위  자연과학       48.0%   양성 0 : 매칭 0   ← 임금 프리미엄 +47.7% (전 계열 최대)
이탈률 4위  IT·컴퓨터      46.4%   양성 5 : 매칭 0   ← AI·SW
이탈률 5위  인문·어학      41.1%   양성 0 : 매칭 0   ← 임금 프리미엄 +12.0% (뚜렷)
```

**전용 사업이 0개인 계열 3개(자연과학·인문어학·생활과학화학)는 전부 임금 프리미엄이 뚜렷하다.**
= 떠나면 실제로 더 번다. 그런데 정책이 없다.

반대로 사업이 몰린 계열(기계·전기전자 7개, IT 5개)은 **반도체·AI·조선처럼 산업 육성 정책이
따로 있는 분야**다. 즉 **정책이 붙은 기준은 이탈률이 아니라 산업 정책의 존재 여부**다.

> **정책 배분이 청년의 실제 이동과 연동돼 있지 않다.**
> 이건 이탈률 순으로 정렬해야만 보인다.

### 도출 인사이트 ③ — 단일 채널로 보면 정책을 틀리게 만든다

채널 토글을 **공공 ↔ 민간**으로 바꾸면 계열별로 최대 4.7배가 달라진다.

| 계열 | 공공(고용24) | 민간(크롤링) | 배수 |
|---|---:|---:|---:|
| **보건·의료** | **2.8%** | **13.4%** | **4.7배** |
| 디자인·예술 | 0.8% | 3.5% | 4.5배 |
| IT·컴퓨터 | 3.2% | 9.0% | 2.8배 |

공공 채널만 보면 *"부산에 의료 일자리가 없다"*, 민간만 보면 *"충분하다"* 가 된다.
**같은 계열을 두고 정반대 정책이 나온다.**

> **공공 고용서비스 데이터 하나로 지역 노동수요를 판단하면 안 된다.**
> 우리가 크롤링을 한 이유이기도 하다 — 이 토글은 그 한계를 숨기지 않고
> **사용자가 직접 확인하는 기능**으로 바꾼 것이다.

### 화면 구조 — 1페이지 4층

```
1층  KPI + 연령별 순이동        (필터 없음, 모두에게 같은 화면)
2층  전공계열 12칩 → 4칸 변경    ← 본체. 인사이트 ①③이 여기서 나온다
3층  12계열 산점도 + 수치 표     ← 전체 지도. 원 클릭으로도 선택
4층  이탈률 순 양성:매칭 막대     ← 인사이트 ②가 여기서 나온다
```

**2층 4칸이 답하는 것**
| 칸 | 질문 | 예 (IT·컴퓨터) |
|---|---|---|
| ① 배출과 수요 | 많이 배출하나 | "배출이 많다" +2.1%p · 연 1,917명 |
| ② 자리는 몇 개 | 경쟁이 센가 | **"7.1명 당 자리 1개"** |
| ③ 남으면/떠나면 | 떠나는 게 이득인가 | "10명 중 5명이 떠났다" 209 → 239만원 |
| ④ 겨냥한 정책 | 뭘 해주고 있나 | **"5 : 0"** 전부 양성 |

### 그림 6장 — 논리 사슬을 그대로 따라간다
```
1. +927 → −5,437          (나갔다)
2. 직업 74.4%              (이유)
3. 배출 vs 수요 구성비       (엇갈린 결)
4. 구인배수 × 대졸요구율     (자리가 없다)
5. 이탈률 × 임금 프리미엄    (떠나거나 하향취업하거나)
6. 양성 : 매칭              (정책은 반대쪽)
```
