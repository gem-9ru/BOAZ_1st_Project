# 2. MECE 설계

## 축 1 — 데이터 조합 (상호배타·전체포괄)

```
Ⅰ. A 단독     부산 일자리가 요구하는 조건
Ⅱ. B 단독     부산 대학이 내보내는 인력과 그 결과
Ⅲ. A × B      엇갈림
Ⅳ. 외부 연결   그래서 떠났는가
```

두 데이터로 만들 수 있는 조합은 이 넷뿐이다. 겹치지 않고 빠지지 않는다.

## 축 2 — 일자리의 6속성

일자리 하나를 기술하려면 여섯 가지가 필요하다.

```
무엇을 (종류)  ·  얼마나 (양)    ·  누구에게 (요건)
얼마에 (보상)  ·  누가 (주체)    ·  어디서 (위치)
```

「언제(시점·계절성)」는 A 가 2026-09-07 단면이라 **볼 수 없다.**
빠진 게 아니라 못 보는 것이므로 명시하고 제외한다.

## 두 축을 겹치면 — 왜 두 데이터가 필요한지가 나온다

| 속성 | A 채용공고 | B 졸업자 통계 |
|---|---|---|
| **종류** | 직종 13대분류 | 계열(중계열 34) |
| **양** | 공고 25,135 · 채용인원 | 졸업자 28,640 · 취업대상 25,236 |
| **요건** | 요구학력 · 경력요건 · 최소연차 | 학제(전문대/4년제/대학원) |
| **보상** | 연봉환산 · 고용형태 | **없음** |
| **주체** | 업종 · 회사 | 학교(국립/사립) |
| **위치** | 시군구 | **없음** (학교 소재지뿐) |
| **결과** | **없음** (뽑혔는지 모름) | 취업률 · 취업형태 · 유지취업률 |

**B 는 보상과 위치를 모르고, A 는 결과를 모른다.**
A = 수요가 내건 조건 · B = 공급이 맞은 결과. 상보적이다. 이게 결합의 논리다.

# 3. 단계별 계획

## Ⅰ. A 단독 — 부산 일자리의 조건  *(대부분 완료, 재배치만)*

| | 분석 | 상태 |
|---|---|---|
| I-1 | 종류 — 직종 13대분류 분포, 규모순 vs 임금순 괴리 | 완료 |
| I-2 | 양 — 공고수 · 채용인원 · 회사 집중도(상위 100곳 7.3%) | 완료 |
| I-3 | 요건 — 학력 × 경력 진입 깔때기, 「1년의 벽」 | 완료 |
| I-4 | 보상 — 연봉 분포, 최저임금선(10분위=2,588만원) | 완료 |
| I-5 | 주체 — 업종별 대졸요구율(학원 61.2% 1위) | 완료 |
| I-6 | 위치 — 시군구 × 직종, 대졸신입 밀도 | 완료 |

→ **할 일: 없음.** 순서만 6속성으로 재배치한다.

## Ⅱ. B 단독 — 부산 대학의 산출과 결과  *(절반 미개척)*

| | 분석 | 상태 |
|---|---|---|
| II-1 | 종류 — 계열 분포 | 완료 |
| II-2 | 양 — 졸업자 → 취업대상자(유학생·진학·입대 제외) | 완료 |
| II-3 | 수준 — 학제별(전문대 71.6% > 4년제 59.4%) | 완료 |
| II-4 | 결과·취업 — 공식 취업률 | 완료 |
| **II-5** | **결과·질 — 취업 형태 분해 (교외/교내/해외/프리랜서/1인창업/창작)** | **미착수** |
| II-6 | 결과·지속 — 유지취업률 1→4차 이탈 곡선 | 완료 |

→ **할 일: II-5.** 계열별로 「임금근로 취업률」을 다시 계산한다.
공식 취업률에서 프리랜서·1인창업·교내취업을 빼면 계열 순위가 바뀔 수 있다.
특히 예술·디자인(프리랜서 비중이 클 것)과 IT.

## Ⅲ. A × B — 엇갈림  *(핵심, 절반 미개척)*

| | 분석 | 상태 |
|---|---|---|
| III-1 | **종류 엇갈림** — 미스매치 지수 (배출비중 − 수요비중) | 완료 |
| III-2 | **요건 엇갈림** — 배출 학력수준 vs 요구 학력수준 → 졸업생 N명당 자리 | 완료 |
| **III-3** | **보상 엇갈림** — B의 취업 질 ↔ A의 일자리 질이 같은 방향인가 | **미착수** |
| **III-4** | **결과 엇갈림** — 미스매치가 큰 계열이 실제로 이탈도 많은가 | 부분 |
| **III-5** | **두 실패 유형의 분리** — IT형(자리 없음) vs 예술형(자리 나쁨) 정량화 | 부분 |

→ **할 일: III-3·III-4·III-5.** 이게 프로젝트의 알맹이다.

- **III-3** A 의 `고용형태 프리랜서 비중`·`최저임금 이하 비율`을 비교축 8칸으로 집계하고,
  B 의 `프리랜서+1인창업 비중`과 대조한다. **두 데이터가 같은 직군을 「나쁜 일자리」로
  지목하면 교차검증이 성립한다.**
- **III-4** 미스매치 지수 ↔ 4차 유지취업률 상관을 계열 단위로 재계산(현재 8칸 → 34중계열
  기준으로 n 을 키운다).
- **III-5** 2×2 로 자른다.
  ```
                수요 있음        수요 없음
  질 좋음    정상            IT형   (자리를 늘려라)
  질 나쁨    예술형          이중실패
  ```
  각 칸에 계열을 배치하고 처방을 다르게 쓴다.
