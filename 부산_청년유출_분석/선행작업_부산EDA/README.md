# 부산_EDA — 배출 ↔ 수요 미스매치 분석 (레포 미포함)

BOAZ 27기 1차 프로젝트 «인재 배출과 기업 수요의 엇갈린 결» 의 분석 작업 폴더.
크롤링 데이터셋 레포(`../크롤링`)와 분리해 둔다. 확정되면 그때 옮긴다.

```
data/  부산소재_고등교육기관_졸업자_취업통계_2024.xlsx   KEDI, 조사기준일 2024-12-31
       서현_학과분석.ipynb                            서현 님 1차 EDA (그룹계열 13분류)
       비교축_매핑.csv                                배출·수요 → 공통 비교축 대응표
src/   mismatch.py                                  미스매치 지수 계산
out/   미스매치_지수.csv                              비교축 8칸 × 12지표
       계열_진단.csv                                 중계열 34종 × 취업률·유지율
```

실행: `python3 src/mismatch.py`  (pandas · openpyxl 필요)

## 방법론 결정 세 가지

**① 배출은 «졸업자» 가 아니라 «취업대상자» 로 센다**
KEDI 공식 취업률의 분모다. `졸업자 − 진학자 − 입대자 − 취업불가능자 −
외국인유학생 − 제외인정자`. 부산 4년제는 졸업자 28,640명 중 외국인유학생이
1,175명(4.1%)이고 경영·경제만 589명(10.8%)이다. 계열마다 유학생·진학 비율이
달라서 졸업자를 그대로 쓰면 배출 비중이 계열별로 다르게 부푼다.
→ 취업대상자 25,236명 · 취업률 59.4% · 미취업 10,257명

**② 비교축을 굵게 잡는다**
두 데이터의 분류축이 다르다(개수만 우연히 13개로 같다). 잘게 붙이면
크로스워크가 결과를 만든다. 실측으로 확인한 사례 셋:
- `12 재료·화학·섬유·가스·에너지·환경` 157건은 재봉사·고무 프레스기 조작원이다.
  화학 전문직 칸이 아니라 경공업 생산직 칸이다.
- 건설 어휘가 든 공고 665건 중 `09 건설·채굴직` 은 26건이고 308건이
  `02 연구직 및 공학기술직` 에 있다. KECO 가 건설 **기술자**(중분류 14)와
  건설 **기능공**(중분류 70)을 다른 대분류에 둔다.
- `인문·어학` 은 대응 직종이 없어 0 이 되고, 지수가 정의상 최대가 된다.

→ 공학·건설·화학을 한 칸으로 묶고, 인문·어학은 지수에서 빼 따로 본다.
   양쪽이 1:1 로 떨어지는 **8칸**만 지수를 낸다.

**③ 「대응 없음」 칸은 결측이 아니라 발견이다**
- 수요 `06 미용·여행·숙박·음식·경비·청소직` 3,959건(16.2%) — 짝이 되는 대학
  계열이 없다. 요양보호사 1,240 · 바리스타 257 · 피부관리사 161 · 호텔청소원 149,
  대졸 이상 요구 0.9%.
- 배출 `인문·어학 + 기타` 3,222명(12.8%) — 짝이 되는 직종이 없다.

억지로 어느 칸에 붙이면 프로젝트가 보려는 것이 사라진다.

## 아직 없는 것

| 필요 | 왜 | 없으면 |
|---|---|---|
| **KEDI 전국·시도별** 같은 통계 | 부산 컴퓨터·통신 취업률 49.8% 가 부산 문제인지 전국 현상인지 갈린다 | «부산이라서» 를 주장할 수 없다 |
| KEDI **취업지역** 항목 | 졸업생이 부산에 취업했나 수도권으로 갔나 | 유출을 직접 못 잰다 |
| KOSIS 부산 시군구 연령별 이동자 | 구별 20대 순유출 × 구별 일자리 구조 | 공간 분석이 안 된다 |

현재 xlsx 의 `시도` 는 전부 «부산» 인데 이건 **학교 소재지**이고 취업 지역이 아니다.
