## 잡플래닛 데이터가 저장소에 없는 이유

잡플래닛은 아래를 게시하고 있습니다.

> "모든 컨텐츠의 무단 전재, **무단 수집**, **재배포** 및 **AI 학습 이용 금지**"

이 저장소는 공개(public)이므로 잡플래닛 수집분을 올리는 것은 "재배포"에 해당합니다.
따라서 `.gitignore` 로 아래 두 파일을 제외했습니다.

- `data/잡플래닛.csv` (1,070건)
- `제외됨/잡플래닛_잡코리아중복.csv` (49,048건)

수집분 50,118건 중 **97.9%(49,048건)는 잡코리아에서 같은 공고를 확보**했으므로
데이터 손실은 사실상 없습니다. 남은 1,070건만 잡플래닛 단독입니다.

재현이 필요하면 코드는 그대로 있습니다.

```bash
python3 src/jobplanet.py                        # 수집
python3 src/pipeline/reconcile_jobplanet.py     # 잡코리아 대조 후 중복분 분리
```
