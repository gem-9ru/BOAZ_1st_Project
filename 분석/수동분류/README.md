# 미분류 2,666건 손으로 붙이기

자동 분류는 공식 명칭 1,130개와의 **문자열 대조**로만 합니다. 그래서 KECO 어휘에
없는 실무 관용어가 통째로 빠집니다 — `생산직`(KECO는 `~원`을 씁니다) ·
`병동`·`원무과`(부서·근무공간) · `피부관리사`·`수의테크니션`(분류표에 없는 신직종).
분류표를 보고 사람이 붙이면 해결됩니다.

```bash
python3 src/pipeline/keco_manual.py sheet    # 시트 다시 만들기 (이미 만들어 뒀습니다)
python3 src/pipeline/keco_manual.py apply    # 채운 시트 검증 + 반영
```

# 파일 셋

| 파일 | 행 | 무엇 |
|---|---:|---|
| `0_직종코드_분류표.csv` | 1,130 | **참조용.** 대분류 → 중분류 → 코드 순 정렬 |
| **`1_토큰_분류.csv`** | **300** | ⭐ 먼저 이걸 채우세요. 미분류의 **51%**(1,969건)가 걸립니다 |
| `2_공고_분류.csv` | 1,885 | 토큰으로 안 걸리는 공고. 한 줄씩 |

## 왜 둘로 나눴나

2,666건을 한 줄씩 보면 오래 걸립니다. 그런데 직무 토큰은 반복됩니다.

```
상위  50개 토큰 → 1,381건 (35.8%)
상위 300개 토큰 → 1,969건 (51.1%)
```

`생산직` 하나 채우면 166건이 붙습니다. 그래서 **토큰으로 절반을 걷고, 안 걸리는
것만 공고 단위로** 봅니다. 토큰이 아예 없는 공고(1,152건)는 제목밖에 단서가 없어
처음부터 공고 단위입니다 — `2_공고_분류.csv` 맨 뒤에 몰아 뒀습니다.

# 채우는 법

`직종코드` 칸에 **확실한 자릿수만** 적으면 됩니다.

| 적는 값 | 뜻 |
|---|---|
| `550102` | 세세분류 — 재가 요양보호사 |
| `5501` | 세분류까지만 확실할 때 |
| `550` | 소분류 |
| `55` | 중분류 |
| `5` | **대분류** — 미용·여행·숙박·음식·경비·돌봄·청소 |
| (빈칸) | 미분류로 남습니다 |
| `x` | 분류 불가로 확정 (빈칸과 구분하고 싶을 때) |

**대분류 1자리만 적어도 충분합니다.** 프로젝트의 미스매치 비교는 대분류 축이고,
자동 분류분의 57%도 대분류만 붙어 있습니다. 무리해서 6자리를 찍지 마세요.

## `후보1~3` 은 힌트일 뿐입니다

글자 겹침으로 고른 것이라 틀립니다. `생산직` 에 `028506 생산관리 사무원` 을
내놓지만 정답은 생산 **현장직**(대분류 8)입니다. 훑는 시간만 줄여 주는 용도입니다.

## 예시

| 직무토큰 | 건수 | 후보1 | 적을 값 | 왜 |
|---|---:|---|---|---|
| `생산직` | 166 | 028506 생산관리 사무원 | `8` | 후보는 사무원. 실제는 생산 현장직 |
| `피부관리사` | 105 | 511400 피부 및 체형 관리사 | `511400` | 후보가 정확 |
| `원무과` | 63 | 026502 병원행정 사무원(원무) | `026502` | 후보가 정확 |
| `md` | 46 | 024302 머천다이저(MD) | `024302` | 후보가 정확 |
| `엔지니어` | 107 | 133301 웹 개발자 | `x` 또는 `2` | 분야를 모르면 특정 불가 |
| `실장` | 85 | (없음) | `x` | 직급이라 직업이 아님 |

`엔지니어`·`실장`·`팀장` 처럼 **직급·범용어는 `x` 로 두는 게 낫습니다.**
억지로 붙이면 미분류율은 내려가지만 분포가 왜곡됩니다.

# 반영

채운 시트를 `data/keco/` 로 옮기면 파이프라인이 계속 기억합니다.

```bash
cp 분석/수동분류/1_토큰_분류.csv data/keco/수동분류_토큰.csv
cp 분석/수동분류/2_공고_분류.csv data/keco/수동분류_공고.csv
python3 src/pipeline/keco_manual.py apply
python3 src/pipeline/refine.py && python3 src/make_deliverable.py
```

`apply` 는 분류표에 없는 코드가 있으면 **아무것도 반영하지 않고 알려줍니다.**
오타를 잡고 다시 돌리면 됩니다.

## 두 가지 보장

**기존 분류를 덮어쓰지 않습니다.** 수동분류는 자동이 미분류로 남긴 공고에만
적용됩니다. 시트를 채워도 지금 정확도(대분류 98% / 세분류 95%)가 나빠질 일이 없습니다.

**다시 돌려도 안 사라집니다.** `keco_run.py build` 가 `data/keco/수동분류_*.csv`
를 함께 읽습니다. 크롤링을 다시 하거나 분류기를 고쳐도 손으로 붙인 값은 살아 있습니다.

## 결과 컬럼

| 컬럼 | 값 |
|---|---|
| `직종코드근거` | `수동분류(토큰)` / `수동분류(공고)` |
| `직종코드확실도` | 6자리를 적으면 `강`, 상위 자릿수면 `중` |
| `직종매칭토큰` | `수동` |

`직종코드근거` 로 필터하면 손으로 붙인 건만 따로 볼 수 있습니다.
공고 시트가 토큰 시트보다 우선합니다 — 그 공고를 직접 보고 붙인 것이므로.
