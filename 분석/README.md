# 2. 무엇을 접었나

## 학력 — 34종 → 6단계 + 미기재

```
학력무관 / 중졸이하 / 고졸 / 전문대졸 / 대학교졸 / 석사이상 / 미기재
```

원본에는 `대학(2,3년)↑` `초대졸↑` `초대졸이상` `대졸(2~3년)~대졸(4년)` 처럼
같은 뜻이 여러 표기로 있었습니다.

**범위는 하한을 씁니다.** `고졸~대졸(4년)` 은 고졸도 받는다는 뜻입니다.
진입장벽을 보려는 것이므로 "최소 무엇을 요구하나" 가 답이어야 합니다.

## 고용형태 — 24종 → 6종 + 복수 플래그

`계약직, 정규직` 처럼 복수값이 2,317건 있었습니다. 대표값만 남기면 안정성을
과대평가하게 되므로 **`고용형태복수` 를 따로 남겼습니다.** 애매한 건을 빼고 볼 수 있습니다.

## 급여 — 형태가 다른 값을 연봉(만원)으로 환산

시급 10,320원과 연봉 3,000만원을 한 축에 놓을 수 없으면 급여 비교가 안 됩니다.
월 소정근로 209시간 · 월 22일 기준입니다.

```
시급 ×209×12    일급 ×22×12    주급 ×52    월급 ×12    연봉 ×1
```

`회사내규`·`협의`·`건별` 은 금액이 없어 빈칸입니다.
**금액이 있는 건은 5,568건(22%)** 입니다 — 급여 미공개가 대다수라는 것 자체가 지표입니다.

## 시군구 — 103종 → 부산 16구군 + 미상

원본에 103종이 들어 있었습니다.

| 원인 | 처리 |
|---|---|
| `진구` 237건 — `부산진구` 가 잘려 들어옴 | `부산진구` 로 합침 |

## 경력 — `기타` 카테고리 제거

`기타` 1,479건 중 758건이 `관계없음`(부산일자리정보망 표기)이었습니다. `무관` 으로 옮겼습니다.
나머지는 경력 칸에 날짜·고용형태가 들어온 행(상위 파싱의 컬럼 밀림)이라 `미기재` 로 뒀습니다.

# 3. 고친 버그 2개

정제하면서 **원본층에도 소급 적용**했습니다 (`src/pipeline/repair_fields.py`).

## 급여 범위의 하한이 날아가고 있었습니다 — 1,868건

```
"연봉 5,027~7,078만원"   →   급여최소 7078 · 급여최대 (빈칸)      ← 잘못
                        →   급여최소 5027 · 급여최대 7078       ← 고침
```

금액 정규식이 숫자 **뒤에** 단위를 요구해서, 단위가 뒤쪽 숫자에만 붙는 표기
(`5,027~7,078만원`)에서 앞 숫자를 놓쳤습니다. 상한값이 하한 칸에 들어가
급여 분석이 위로 편향되고 있었습니다.

## `관계없음` 이 경력 `기타` 로 빠지고 있었습니다 — 1,479건

`무관` 이 13,922 → 14,680건으로 늘었습니다.
