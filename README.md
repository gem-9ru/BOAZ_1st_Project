# 채용공고 통합 데이터셋 — 부산 지역 추출

BOAZ 1st Project · 국내 채용 사이트 **18곳**을 수집해 하나의 스키마로 정규화하고,
사이트 간 중복을 병합한 뒤 **부산 지역 공고만 추출**한 데이터셋입니다.

**스냅샷 기준일 `2026-09-07`** — 이 날짜에 실제로 모집 중이던 공고만 담았습니다.

```
수집 213,169행  →  정규화 200,502행  →  중복병합 157,007건  →  부산 20,622건
```

## 빠른 시작

```bash
pip install -r requirements.txt
```

이미 수집된 `data/*.csv` 가 있으므로 **재수집 없이** 파이프라인만 돌릴 수 있습니다.

```bash
python3 src/pipeline/normalize.py      # data/*.csv  -> build/공고_정규화.csv
python3 src/pipeline/dedup.py          # 중복 병합    -> build/공고_통합.csv
python3 src/pipeline/extract_busan.py  # 부산 추출    -> 부산/
```

중복 제거 로직 회귀 테스트:

```bash
python3 src/pipeline/test_relation.py
```

특정 사이트를 새로 수집하려면 (체크포인트 방식이라 중단해도 이어서 실행됩니다):

```bash
python3 src/wanted.py
```
