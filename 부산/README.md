| 파일 | 건수 | 설명 |
|---|---:|---|
| **`부산_공고_통합.csv`** | **25,276** | ⭐ **최종 결과물.** 중복 제거된 부산 지역 공고 · 33컬럼 |
| `부산_공고_원본.csv` | 57,375 | 병합 전 행 + `부산판정근거`·`부산판정확실도` |

**`부산_공고_통합.csv` 가 이 프로젝트의 결과물입니다.**
행 하나가 공고 하나이고, 같은 공고가 여러 사이트에 올라온 경우 하나로 합쳐져 있습니다.

## 부산판정확실도로 걸러 쓰세요

| 확실도 | 건수 | 근거 |
|---|---:|---|
| **강** | 23,561 | 시도=부산 · 상세 근무지주소가 부산 · 부산 시군구 |
| 중 | 1,564 | 다지역 공고에 부산 포함 · 부산포털인데 지역 미상 |
| 약 | 151 | 제목에만 부산 (근무지주소 없음) |

엄격하게 쓰려면 `부산판정확실도 == "강"` 만 쓰면 됩니다.

> `부산_판정보류.csv` 는 더 이상 만들지 않습니다.
> "제목엔 부산인데 근무지주소는 타지역" 인 행을 담으려 했는데, 실제로 0건입니다.
> 상세 근무지주소가 있는 공고는 이미 앞 단계 판정을 통과하기 때문입니다.
