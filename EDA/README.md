## 지금 정할 것 3가지

1. 헤드라인 문장을 위 문장으로 갈 것인가
2. **포스터를 몇 칸으로 갈 것인가** — 대시보드는 7칸이지만
   ⑦번(선행연구 대조)은 포스터보다 **발표 슬라이드에 더 맞다**
3. 전공과 채용의 어긋남을 **「몇 배」 대신 「비율 차이(%p)」**로만 표현할 것인가
   ← 이건 바꾸면 안 된다
