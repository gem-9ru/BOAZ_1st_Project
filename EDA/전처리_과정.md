# 데이터 전처리 — 원자료에서 대시보드 숫자까지

**왜 이 문서가 필요한가.** 이 프로젝트의 숫자는 원자료를 그대로 센 게 아니다.
서로 다른 축으로 만들어진 자료 5종을 **하나의 축(직업 6자리 코드 · 12계열)으로 옮긴 뒤** 센 것이다.
그 옮기는 과정에서 **가정이 들어간다.** 어디에 무슨 가정이 들어갔는지 적어둔다.
심사에서 가장 깊게 파고들 곳이고, 우리가 가장 자신 있는 곳이기도 하다.

**전체 흐름**

```
[1] 채용공고 수집·정리     240,773행 → 25,135건
[2] 직업 코드 부여          공고 → 고용노동부 6자리 직업코드
[3] 학과 → 직업 대응        학과 중계열 → 직업 대분류 (1:N 가중 배분)
[4] 계열 통합               두 축을 12계열로 합침 (총계 보존 정규화)
[5] 졸업생 추적조사 정리     4개 연도 합치기 · 코드 체계 어긋남 보정
[6] 소득 비교 준비          조건을 맞춘 뒤 비교하기 위한 통제 변수 구성
[7] 주거비 층화             거주 형태를 고정해 구성 차이 제거
[8] 업종 · 지역 정리        업종 원문 721종 → 9개군 · 구·군 추출
[9] 생활인구 · 정책 정리     일별 데이터 집계 · 정책 109개 분류
[10] 품질 점검              표본 수 · 이상치 · 관계 주장의 견고성
```

## [2] 직업 코드 부여 — 가장 손이 많이 간 단계

공고는 「무슨 일인지」를 사이트마다 다른 깊이로 적는다.
그래서 한 칸에 몰지 않고 **6단계 우선순위로 합성**했다. 앞쪽일수록 신뢰도가 높다.

```
1. 직종 (사이트가 분류한 표준 명칭)     → 그대로 신뢰
2. 직무키워드 (사이트가 붙인 직무 코드)  → 그대로 신뢰
3. 직무상세 (모집분야)                ┐
4. 원본 직무 칸                       │  직무 어휘 사전(약 350개)으로
5. 공고제목                           │  걸러서 사용
6. 담당업무 첫 문장                    ┘
```

이렇게 만든 직무 텍스트를 **고용노동부 한국고용직업분류(KECO) 6자리 코드**에 붙였다.

**보정 장치 3개**

| 장치 | 무엇 |
|---|---|
| `직종신뢰도` | 몇 단계에서 왔는지를 점수로 남김 — 낮은 것만 따로 검토 가능 |
| `직종추정코드` + `직종추정근거` | 확실하지 않은 것은 **추정 칸에 따로** 담고 근거를 적음 |
| `직종미분류사유` | 왜 못 붙였는지 기록 |

**남은 미분류 1,206건(4.8%).** 이건 감추지 않고 분석에서 제외한 뒤 각주에 명시한다.

> ⚠️ **팀 작업 규칙** — 팀원 간 데이터를 합칠 때는 **반드시 6자리 코드로** 붙인다.
> 문서마다 13개 큰 분류의 **이름 체계가 다르다.**
> 어떤 문서는 13번이 「정보통신관련직」, 고용24 공식 마스터는 13번이 「농림어업직」이다.
> 이름으로 붙이면 표 전체가 어긋난다.

## [3] 학과 → 직업 대응 — 여기가 가장 큰 가정이다

**문제.** 졸업생은 「학과」로 세고, 공고는 「직업」으로 센다. 축이 다르다.
비교하려면 학과를 직업으로 옮겨야 하는데, **한 학과가 한 직업으로 가지 않는다.**

**해법 — 1:N 가중 배분.** 하나의 학과 중계열을 여러 직업에 비율로 나눴다.

```
경영ㆍ경제   → 경영·사무·금융·보험  0.8
            → 영업·판매·운전·운송  0.2

산업(산업공학) → 경영·사무·금융·보험 0.7    (생산관리·기획 사무)
              → 연구·공학기술      0.3    (공학기술 트랙)

교통ㆍ운송    → 경영·사무 0.5 / 설치·정비·생산 0.25 / 영업·판매·운전·운송 0.25
```

전체 **54줄**이고, 각 줄마다 `근거` 칸에 왜 그 비율인지 적어뒀다(`build/crosswalk.csv`).

### 이 가정을 검증한 방법 — 114가지 경우를 전부 돌렸다

가중치는 우리가 정한 것이므로 **결론이 이 표에 의존하면 안 된다.** 그래서 전부 흔들어봤다.

```
대응표     19가지 변형
학제        3가지 (4년제만 / 전문대 포함 / 교대 포함)
수요 정의   2가지 (공공 구인 / 민간 공고)
= 114가지 경우
```

**결과 — 「수요의 3.41배 배출」이 0.84배 ~ 3.95배로 흔들렸다.**
기준을 바꾸면 방향까지 뒤집힌다. 그래서 **배율 주장을 통째로 버렸다.**
살아남은 것은 **비율 차이(%p)** 로 말하는 부분뿐이다.

> 이 검증을 안 했으면 포스터에 「3.41배」를 크게 쓰고 심사에서 무너졌을 것이다.

**대응표를 실제로 두 번 고쳤다**

| 발견 | 고침 |
|---|---|
| 물류·운송 계열이 **8.1명당 대졸신입 1개**로 비정상 (선행 계산은 324명당) | 「교통ㆍ운송」이 해양공학 90%인데 공학기술직 경로가 없었다 → 배분 추가. **32.7명당으로 정상화** |
| 경영·경제에서 영업직 경로 누락 | 0.8 / 0.2로 분할 |

고친 뒤 **114가지를 다시 돌려 결론이 안 바뀌는 것을 확인**했다.

## [4] 계열 통합 — 총계가 보존되게 정규화

학과 중계열을 **12개 계열**로 묶고(경영·사무 / 기계·전기전자 / 보건·의료 …),
직업 대분류 10종의 공고를 계열별로 나눠 받아야 한다.

**그냥 나누면 총계가 안 맞는다.** 한 직업의 공고를 여러 계열이 나눠 받을 때
비율 합이 1이 되도록 **열 기준으로 정규화**했다.

```
A        = 계열 × 직업 배분 행렬 (졸업생 수 × 가중치)
COLSHARE = A ÷ (각 직업 열의 합)     ← 열 합이 1이 되게
계열별 공고 = COLSHARE × 직업별 공고 수
```

이렇게 하면 **직업별 공고 총계가 그대로 보존**된다.

### 「전용도」 — 배분 가정에 얼마나 기대는지를 수치로

```
전용도 = 받은 공고 1건당, 그 직업에서 내가 차지한 평균 지분
```

전용도가 **0.5 미만**이면 「어느 직업에서도 주된 수요자가 아니다」는 뜻이고,
그 계열의 숫자는 **배분 가정에 크게 좌우된다**. 해당 계열에 `배분의존 = True` 표시를 달았다.
발표에서 그 계열 숫자를 말할 때는 이 점을 먼저 밝힌다.

## [5] 졸업생 추적조사(GOMS) 정리

**원자료** 한국고용정보원 대졸자직업이동경로조사, 2016·2017·2018·2019년 졸업생

### ① 4개 연도 합치기

한 해만 쓰면 부산 표본이 부족하다(IT·컴퓨터 계열이 31명이었다).
다행히 이 조사는 **변수 이름 앞부분만 연도마다 다르고 뒷부분은 같다.**

```
g161wt · g171wt · g181wt · g191wt   →  앞 4글자를 떼면 전부 wt
```

앞부분을 떼고 이어붙였다 → **전체 72,714명 · 부산 소재 대학 졸업자 6,579명**
IT·컴퓨터 계열 표본이 **31명 → 211명**이 됐다.

> 연도를 합쳤으므로 회귀에 **졸업연도 더미**를 넣어 연도 효과를 분리했다.

### ② 코드 체계 어긋남 보정 — 안 했으면 표 전체가 밀렸다

2018년 자료의 직업 대분류가 **1~10으로 매겨져 있었다.** 다른 연도는 **0~9**다.

```
2018년만  -1  오프셋 보정
```

발견 못 했으면 2018년 전체가 **한 칸씩 밀린 채로** 집계됐을 것이다.

### ③ 전공 → 계열 매핑

조사의 전공 소분류(약 150종)를 **정규식으로 12계열에 배정**했다.
팀 크로스워크와 **같은 12계열 축**을 쓴다.

```
IT·컴퓨터    ← ^(전산|응용소프트웨어|정보/통신)
기계·전기전자 ← ^(기계|금속|전기|전자|신소재|재료|반도체|제어계측|자동차|…)
보건·의료    ← ^(간호|의학|치의학|한의학|약학|보건|재활|의무행정|동물/수의)
```

### ④ 「떠났다」의 정의

```
지역 = 현재 일자리 지역(d020)
       없으면 → 첫 일자리 지역(a014)
떠남 = 지역이 부산이 아님
수도권 = 서울 · 인천 · 경기
```

일자리 지역이 확인되는 사람만 대상으로 했다.

### ⑤ 표본 가중치 적용

이 조사는 **표본 조사**라 사람마다 가중치(`wt`)가 다르다.
모든 평균·비율을 **가중평균**으로 계산했다. 단순 평균을 쓰면 모집단과 어긋난다.

## [6] 소득 비교 — 조건을 맞춘 뒤 비교하기

「서울이 원래 임금이 높다」는 당연한 반론이다. 그래서 **사람 조건을 맞춘 뒤** 비교했다.

```
소득에 로그를 씌우고    ← 비율 차이로 해석하기 위해
아래를 같이 넣어 통제:
   떠남 여부 · 성별 · 학교 유형(사립) · 졸업연도 · 학점 · 전공
표본 가중치를 반영한 회귀 + 표준오차는 보수적으로 계산
```

**직접 구현했다** (`statsmodels`·`scipy` 없이 numpy만으로).
그래서 계수·표준오차·t값이 어떻게 나오는지 전부 들여다볼 수 있다.

**중간에 걸린 오류 하나** — 회귀가 계산 불가로 멈췄다.
원인은 **값이 전부 0인 열**(학점 결측 표시 변수)이 들어간 것. 그 열을 빼고 해결했다.

**결과 해석 규칙** — 계열별로 「차이가 통계적으로 확인된 계열」만 진하게 표시한다.
확인 안 된 계열은 **차이가 없다는 뜻이 아니라 이 표본으로는 말할 수 없다**는 뜻이다.

## [7] 주거비 — 구성 차이를 제거한 층화 비교

**왜 했나.** 「부산에서 덜 벌어도 고정 지출이 적으면 상쇄된다」는 반론을 막기 위해서다.

**자료 선택.** 지역 평균 전월세가를 갖다 붙이지 않고,
같은 조사의 **「전년도 월평균 주거비 지출액」** 문항을 썼다.
**같은 사람의 소득과 주거비를 함께** 볼 수 있어 지역 평균보다 정확하다.
단, 이 문항은 **2018·2019년 졸업생에만** 있다(부산 1,122명).

### 첫 계산이 틀렸고, 왜 틀렸는지 찾았다

```
전체 평균:  부산 잔류 41.1만원  vs  수도권 이탈 35.0만원   ← 부산이 더 많이 낸다?
```

원인은 **거주 형태 구성이 다르기 때문**이었다.

```
              자취·분가   부모집   기숙사·사택
부산 잔류        72.3%    22.3%      3.5%
수도권 이탈      80.4%     6.2%     12.0%
```

부산 잔류자는 **부모집 거주가 3.6배 많다.**
부모집 응답은 **가구 전체 지출을 적는 경우가 섞여** 값이 비정상적으로 높게 잡힌다.

### 해법 — 거주 형태를 고정(층화)

```
보증금 월세 · 이상치 제외   부산 37.7 (212명)  vs  수도권 43.5 (124명)  → 차이 5.8만원
  → 소득 차이 40.3만원 중 월세가 메워주는 몫 14%, 남는 격차 34.5만원 (86%)
  → 중앙값 기준으로도 명목 40 · 월세 8 · 남는 격차 32만원 (80%)
```

### 왜 세 겹으로 걸러야 하나 — 한 겹씩 벗길 때마다 답이 달라졌다

| 거른 정도 | 부산 | 수도권 | 차이 | 문제 |
|---|---|---|---|---|
| 전체 | 41.1 | 35.0 | **−6.1** | 부모집 거주자(부산 22.3%)가 값을 부풀린다 |
| + 자취·분가만 | 34.9 | 37.5 | +2.6 | 전세·자가가 섞인다 — **수도권이 전세 42.4%라 과소평가** |
| + 보증금 월세만 | 43.0 | 43.5 | +0.5 | 부산에 **월 732만원 같은 오기**가 섞여 부산이 부풀려진다 |
| **+ 이상치 제외** | **37.7** | **43.5** | **+5.8** | ← 이것이 주 수치 |

**세 번째 줄(차이 0.5만원)을 한동안 주 수치로 썼는데 틀렸다.**
부산 쪽에 오기 몇 건이 섞여 평균이 43.0으로 부풀려져 있었다.
이상치를 빼니 부산은 37.7로 내려가고 **차이가 5.8만원으로 커졌다.**

> 층화를 안 했으면 「부산이 주거비를 더 낸다」는 **정반대 결론**을,
> 이상치를 안 뺐으면 「차이가 0.5만원뿐」이라는 **과장된 결론**을 낼 뻔했다.

## [8] 업종과 지역 정리

### 업종 — 원문 721종 → 9개군

채용 사이트가 적는 업종 이름이 제각각이다
(「의료(진료과목별)」「기계·설비·자동차」「응용 소프트웨어 개발 및 공급업」…).
**정규식 규칙을 위에서부터 적용**해 9개군으로 묶었다.

```
보건·의료·복지 ← 의료|병원|제약|바이오|보건|간호|사회복지|요양

제조          ← 기계|설비|자동차|조선|항공|전기|전자|금속|철강|제조|화학 …
```

> ⚠️ **업종 미상·기타가 31.6%**다. 그래서 업종은 **구성 비교에만 쓰고 순위는 주장하지 않는다.**

## [9] 생활인구와 정책

### 생활인구 — 일별 데이터를 지표로

부산 데이터오픈랩(Big-데이터웨이브)의 **행정동 일별 연령별 생활인구**
(2023.01~2025.12, 44,340행)를 평균 내어 두 개를 만들었다.

```
청년유입비 = 20대 직장인구 ÷ 20대 주거인구
   높다 → 청년이 「일하러 오는」 지역
   낮다 → 청년이 살지만 다른 데로 일하러 나가는 지역

청년 1만명당 대졸신입 공고 = 대졸신입 공고 ÷ 청년 주거인구 × 10,000
```

**이걸로 「자리는 강서구, 청년은 부산진구」가 수치로 나왔다** (281.6 ↔ 31.0).

### 정책 — 109개를 두 축으로 분류

부산시 2025년 청년정책 시행계획(109개 사업 · 4,146억원)을
**① 대상 계열 ② 정책 성격(인재 키우기 / 일자리 연결 / 창업)** 두 축으로 분류했다.

> 이 분류는 **사람이 읽고 판단한 것**이라 주관이 들어간다. **팀 검토가 필요하다**(30분).

## [10] 품질 점검 — 모든 숫자에 같은 검사를 돌린다

분석 도중 **점 몇 개 중 튀는 하나를 보고 구조라고 말한 실수를 두 번** 했다
(「상관 +0.68」과 「대졸 부르는 업종일수록 불안정」). 두 번 다 스스로 찾아 철회했지만,
**같은 실수가 또 나지 않도록 절차로 만들었다.** → `build/quality.py`

### ① 표본 수 — 비율을 몇 자리까지 말해도 되는가

비율의 **95% 오차범위**(±1.96√(p(1−p)/n))를 계산해 세 구간으로 나눈다.

```
n ≥ 100   사용 가능 — 소수점 한 자리까지 표시
30 ≤ n < 100  표본 적음 — 별표(*) 표시 + 흐리게 그림
n < 30    표시 금지 — 아예 그리지 않는다
```

**걸린 것 3개**

| 어디 | 항목 | 표본 | 비율 | 오차범위 |
|---|---|---|---|---|
| ②③번 칸 | 건설·채굴 | 76건 | 5.3% | **±5.0%p** |
| ②③번 칸 | 농림어업 | 62건 | 1.6% | **±3.1%p** |
| ⑤번 칸 | 농림·수산 | 0명 | — | 표시 안 함 |

건설·채굴의 「5.3%」는 오차범위가 ±5.0%p라 **0.3%일 수도 10.3%일 수도 있다.**
그래서 대시보드에서 흐리게 그리고 별표를 붙였다.

### ② 이상치 — 극단값이 결론을 바꾸는가

GOMS 월소득에 **월 2,500만원 같은 값이 42건** 있다(오기로 보인다).
무응답 코드(−1, 16건)는 원래부터 제외돼 있었다. 처리 방식을 바꿔가며 다시 계산했다.

| 처리 | 부산 잔류 | 수도권 | 격차 |
|---|---|---|---|
| 무응답만 제외 (기준) | 205.0 | 242.3 | **+37.3** |
| 월 1,000만원 초과 제외 | 203.5 | 241.2 | **+37.7** |
| 월 500만원 초과 제외 | 199.3 | 236.5 | **+37.1** |
| 상하위 1% 절단 | 200.9 | 237.9 | **+37.0** |
| 상하위 1% 값 대체 | 202.5 | 239.3 | **+36.7** |
| 중앙값 기준 | 200.0 | 230.0 | +30.0 |

**어떻게 처리해도 36.7~37.7만원.** 중앙값으로는 30만원으로 낮아지지만 방향은 같다.
→ **헤드라인 숫자를 바꾸지 않았다.** 극단값에 기대는 값이 아니기 때문이다.
(바뀌었다면 바꿨을 것이다. 그래서 재본 것이다.)

### ③ 관계 주장 — 점 하나를 빼면 어떻게 되나

「A일수록 B하다」를 말하기 전에 **점을 하나씩 빼면서 상관을 다시 계산**한다.
부호가 뒤집히면 쓰지 않는다.

| 주장 | n | 관계 | 하나씩 빼면 | 판정 |
|---|---|---|---|---|
| 업종: 대졸 요구 ~ 정규직 | 10 | −0.23 | −0.53 ~ **+0.30** | **쓸 수 없음** (부호 뒤집힘) |
| 계열: 떠난 비율 ~ 자리 여유 | 11 | +0.25 | +0.04 ~ +0.55 | **쓸 수 없음** |
| 7대계열: 떠난 비율 ~ 자리 여유 | 7 | +0.31 | +0.21 ~ +0.56 | **쓸 수 없음** |
| 구·군: 대졸 요구 ~ 정규직 | 16 | +0.40 | +0.00 ~ +0.51 | **쓸 수 없음** |

**네 개 전부 못 쓴다.** 그래서 이 프로젝트는 **「A일수록 B하다」는 문장을 하나도 쓰지 않는다.**
대신 **구성비(%)와 격차(%p)**로만 말한다.

> 이게 약점이 아니라 강점이다. 심사에서 "이 상관 믿을 수 있나요?"라는 질문이
> 나올 자리를 **미리 없앤 것**이다.
