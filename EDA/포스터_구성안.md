# 포스터 구성안 — 7칸 + 제안

**제목** → 원래 주제 그대로 「**인재 배출과 기업 수요의 엇갈린 결**」
**부제** → 부산 대학은 대졸을 내보내고, 부산 일자리는 대졸을 따로 찾지 않는다
           — 그 대가가 월 **37.7만원**이다
**읽는 순서** 왼쪽 위에서 오른쪽 아래로, Z자.
**칸 제목은 결론 문장으로 쓴다.** 「~현황」 같은 제목은 쓰지 않는다.

```

│               │ 안 찾음 ★     │                             │
├───────────────┴───────────────┼─────────────────────────────┤
│ ④ 대졸을 찾는 자리가 어디에  │ ⑤ 그래서 떠난다 — 임금       │
│    업종 + 정규직 비율           │    떠난 비율 · 월 37.7만원   │

│ ⑥ 주거비로     │ ⑦ 이미 알려진 것과 우리가 더한 것 (선택)      │
│    상쇄되나 →  │    — 포스터가 빡빡하면 발표로 뺀다            │
│    안 된다     │                                             │
├───────────────┴─────────────────────────────────────────────┤
```

## ⑥ 덜 받아도 주거비가 싸면 상쇄되는 것 아닌가 — 실제로 재봤다

**이 칸은 ⑤의 결론을 지키는 칸이다.** 37.7만원을 덜 벌어도 나가는 돈이 그만큼 적으면
손에 남는 건 같다. 「부산은 집값이 싸잖나」는 **임금 격차 주장을 통째로 무너뜨릴 수 있는
거의 유일한 반론**이라, 반드시 먼저 막아야 한다.

| | |
|---|---|
| **그래프 A** | 가로 막대 3개 — 월소득 차이 +37.9 / 주거비가 상쇄하는 몫 +2.6 / 그래도 남는 차이 +35.3<br>**세 번째 막대가 첫 번째와 거의 같은 길이**인 게 눈으로 보이는 게 핵심 |
| **그래프 B** | 행선지별 월소득을 「주거비」와 「그 외」로 나눈 누적 막대 |
| **데이터** | `근거데이터/주거비_행선지.csv` |
| **내용** | 혼자 사는 사람끼리 — 부산 37.7 vs 수도권 43.5만원(차이 5.8)<br>보증금 월세만 — 부산 43.0 vs 수도권 43.5만원(**차이 0.5**)<br>→ 상쇄되는 몫은 **7%**, **80~86%가 그대로 남는다** |
| **꼭 넣을 설명** | 부모집 거주자가 섞이면 부산 쪽이 부풀려진다(부산 22.3% vs 수도권 6.2%).<br>그래서 **혼자 살거나 분가한 사람만** 비교했다 — 부산 366명, 수도권 238명 |
| **주의** | 국가지표 RIR(소득 대비 임대료)은 수도권 20%·지방 광역시 15%로 **수도권 부담이 더 크다**고 나온다.<br>그건 **모든 가구의 중위값**이고 우리는 **혼자 사는 대졸 청년**이다. 재는 대상이 다르다 |

## ⑦ 이미 알려진 것과, 우리가 더한 것

> **포스터에 넣을지 발표로 뺄지 정해야 한다.** 내용은 좋지만 칸을 많이 먹는다.
> 포스터가 빡빡하면 **⑤번 각주에 「한국은행 500만원 ↔ 우리 452만원」 한 줄만** 살려도 된다.

|---|---|
| **표 A** | 기존 자료와 결론이 맞는지 — 5개 항목 전부 일치 |
| **표 B** | 기존 자료가 멈춘 자리 / 우리가 한 것 |
| **데이터** | `선행연구_정리.md` (웹 자료) |
| **내용** | 유출 사유 1위 직업 66.5%(부산시) ↔ 54.7%(우리)<br>임금 격차 연 500만원(한국은행 2012) ↔ **연 452만원**(우리)<br>지역 잔존율 61.5% ↔ 약 60% |
| **한 줄** | **기존 자료는 「왜 떠나는가」에 답했다. 우리는 「그 일자리의 무엇이 문제인가」에 답한다** |
| **주의** | 이 수치들은 **언론 보도·기관 요약**에서 확인한 것이다. 인용 전 **원문 대조 필수** |

## 제안 — 「더 키우기」가 아니라 「첫 1년 버티기」

| **제안 3줄** | ① 첫 1년 정착 지원을 **인재 키우기 예산에서 옮겨온다**<br>② 부산진구 월세 지원보다 **강서구로 갈 수 있게 하는 것**(교통·기숙)이 먼저다<br>③ 대졸을 부르는 업종(교육·IT)에 **고용 안정성 조건**을 건다 |
| **주의** | 정책 분류는 **사람이 읽고 판단한 것**이다. 팀 검토를 거친 뒤 쓴다 |

## 그래프 만들 때 지킬 규칙

- **세로축 두 개짜리 그래프는 만들지 않는다.** 단위가 다른 값은 그래프를 나눈다
- 계열 색은 **한 번 정하면 끝까지 고정**. 여섯 칸 전부에서 같은 계열은 같은 색
- 숫자 라벨은 **강조할 것에만**. 모든 막대에 숫자를 붙이지 않는다
- 글씨는 검정·회색 계열로. 색은 막대와 점에만 쓴다
- **「몇 배」와 「순위」 주장 금지.** 비율(%)과 비율 차이(%p)로만
- 각 칸 아래에 **출처와 기준 시점**을 작게 반드시 적는다
