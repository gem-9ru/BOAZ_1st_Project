# ① 과정 — 열두 번 갈아엎었다

대시보드는 처음부터 그림을 그린 게 아니라, **질문이 계속 틀린 걸로 판명되면서 바뀐 결과물**이다.
버린 것을 포함해서 적는다. 발표에서 이게 제일 강한 재료다.

## 1단계 — 처음 질문: "부산은 전공을 너무 많이 배출하는가"

학과 배출과 채용 수요를 맞춰봤더니 **「수요의 3.41배를 배출한다」**가 나왔다. 여기서 멈출 뻔했다.

**그런데 기준을 바꿔서 다시 재봤다.**
학과를 직업으로 옮기는 대응표를 19가지, 어떤 학교까지 포함할지를 3가지,
「수요」를 무엇으로 볼지를 2가지 — **114가지 경우를 전부** 돌렸다.

```
결과: 0.84배 ~ 3.95배
```

**기준을 바꾸면 「많이 배출한다」가 「오히려 적게 배출한다」로 뒤집혔다.**
→ **배율 주장을 통째로 버렸다.** 이게 첫 번째 큰 전환이다.

## 2단계 — 두 번째 질문: "자리가 적어서 떠나는가"

그렇다면 자리가 적은 계열일수록 더 많이 떠나야 한다.
「떠난 비율」과 「자리 여유」가 **반대로 움직여야** 한다.

계열을 묶는 방식 4가지로 전부 쟀는데 **넷 다 같은 방향(+)으로 움직였고, 넷 다 우연일 확률이 9~50%**였다.

→ **「자리의 개수로는 설명할 수 없다」**가 확인됐다.
주의: 「자리가 많아서 떠난다」는 뜻이 **아니다.** 어느 쪽도 입증 안 된 것이다.

> 여기서 막혔다. 원인이 일자리인 건 맞는데, 개수가 아니면 대체 무엇인가?

## 3단계 — 질문을 바꿨다: "그럼 그 자리가 어떤 자리인가"

팀이 정한 세 하위 항목(**요구 학력 · 고용 형태 · 구별 산업**)이 정확히 이 빈자리를 메웠다.
공고 25,135건을 학력으로 갈랐더니:

```
4년제 이상을 요구      2,315건  (9.2%)
  + 신입도 지원 가능   1,070건  (4.3%)
  + 정규직                816건  (3.2%)   ★
```

**여기서 대시보드의 축이 정해졌다.**
처음엔 「대졸이 갈 자리가 없다」로 잡았는데 **이건 비약이었다** —
요구 학력은 대개 하한선이라 학력무관·전문대·고졸 공고에도 대졸은 지원할 수 있다.
**대졸이 지원 가능한 자리는 94%다.** 그래서 제목을 원래 주제로 되돌렸다.

> **인재 배출과 기업 수요의 엇갈린 결**
> 부산 대학은 대졸을 내보내고, 부산 일자리는 **대졸을 따로 찾지 않는다**

3.2%는 「갈 수 있는 자리」가 아니라 **「기업이 대졸이라는 점에 값을 매기는 자리」**다.

## 4단계 — 결과 확인: 그래서 실제로 손해를 보는가

정부가 대졸자를 졸업 후까지 추적하는 조사로 소득을 비교했다.
서울이 원래 임금이 높은 건 당연하므로, **전공·학점·성별·졸업연도를 똑같이 맞춘 뒤** 다시 쟀다.

```
부산에 남은 사람 207.0만원  vs  수도권으로 간 사람 244.7만원  →  월 37.7만원
```

## 5단계 — 스스로 반론을 걸었다: "덜 받아도 덜 쓰면 상쇄되지 않나"

**이게 임금 격차 주장을 통째로 무너뜨릴 수 있는 거의 유일한 반론이다.**
부산에서 37.7만원 덜 벌어도 매달 나가는 고정 지출이 그만큼 적다면 손에 남는 돈은 같다.

지역 평균 전월세가를 갖다 붙이는 대신, **같은 사람에게 소득과 주거비를 함께 물어본** 조사 항목을 찾아 썼다.

**첫 계산은 예상과 정반대로 나왔다** — 부산 잔류자가 오히려 더 많이 냈다(41.1 vs 35.0).
파보니 **부산 잔류자는 부모집 거주가 22.3%**(수도권 6.2%)였고,
그 응답은 가구 전체 지출을 적는 경우가 섞여 값이 부풀려져 있었다.

**그런데 거주 형태만 고정하는 걸로는 부족했다.** 세 겹으로 걸러야 한다.

```
보증금 월세 · 이상치 제외   부산 37.7 (212명)  vs  수도권 43.5 (124명)  → 차이 5.8만원
→ 소득 차이 40.3만원 중 월세가 메워주는 몫은 14%, 86%가 그대로 남는다
```

세 겹 —  ① **부모집 거주자 제외**(가구 전체 지출이 섞임) ② **보증금 월세만**
(전세·자가는 관리비·이자뿐이고, 수도권이 전세 42.4%라 섞으면 수도권이 과소평가된다)
③ **이상치 제외**(월 732만원 같은 오기).

> **한 겹만 벗겼을 때는 「차이 0.5만원」이 나왔는데 틀린 값이었다.**
> 부산 쪽에 오기 몇 건이 섞여 평균이 부풀려져 있었다.
> 세 겹을 다 벗기니 **차이 5.8만원**으로 커졌다. 결론은 유지되지만 크기가 달라졌다.
> 이 단계가 없었으면 **「거의 같다」는 과장된 주장**을 할 뻔했다.

## 6단계 — 마지막으로 기존 연구와 맞춰봤다

우리 숫자가 튀는 값인지 확인했다. **다섯 항목 전부 맞았다.**

| 항목 | 기존 자료 | 우리 결과 |
|---|---|---|
| 유출 사유 1위 | 직업 66.5% (부산시 2024) | 직업 54.7% |
| 순유입 요인 | 교육 > 주거환경 (부산연구원 2022) | 교육 +3,479 · 주거환경 +915 |
| 연령 | 25~29세 최다 | 25-29세 순유출률 전국 2위 |
| 임금 격차 | 연 약 500만원 (한국은행 2012) | **연 452만원** |
| 지역 잔존율 | 61.5% (한국은행 2012) | 약 60% |

→ 대시보드 ⑦번 칸이 이것이다. 자세한 건 `선행연구_정리.md`.

## 7단계 — 마지막으로, 모든 숫자를 스스로 흔들어봤다

과정에서 **점 몇 개 중 튀는 하나를 보고 구조라고 말한 실수를 두 번** 했다.
두 번 다 스스로 찾아 철회했지만, 같은 실수가 또 나지 않도록 **절차로 만들었다**
(`build/quality.py`). 세 가지를 모든 숫자에 돌린다.

**① 표본이 충분한가** — 비율의 95% 오차범위로 3구간
```
n ≥ 100   사용 가능      30~99  별표(*)·흐리게      n < 30  표시 금지
```
걸린 것: 건설·채굴 76건(±5.0%p) · 농림어업 62건(±3.1%p)

**② 극단값이 결론을 바꾸는가** — 처리 방식을 바꿔가며 재계산
```
임금 격차   6가지 처리 전부 36.7~37.7만원   → 견고, 헤드라인 유지
주거비      이상치를 빼니 0.5만원 → 5.8만원  → 무너짐, 수치 정정
```

**③ 관계 주장이 점 하나에 기대는가** — 하나씩 빼면서 다시 계산
```
업종: 대졸요구 ~ 정규직    n=10  −0.23 → 하나 빼면 −0.53~+0.30  부호 뒤집힘
계열: 떠난비율 ~ 자리여유  n=11  +0.25 → +0.04~+0.55
구·군: 대졸요구 ~ 정규직   n=16  +0.40 → +0.00~+0.51
```
**네 개 전부 못 쓴다.** 그래서 이 프로젝트는
**「A일수록 B하다」는 문장을 하나도 쓰지 않는다.** 구성비(%)와 격차(%p)로만 말한다.

> 이게 약점이 아니라 강점이다.
> 심사에서 "이 상관 믿을 수 있나요?"가 나올 자리를 **미리 없앤 것**이다.

## 정리 — 대시보드 8칸은 이 과정 그대로다

```
①  공급          부산은 해마다 3.6만명을 배출한다
②  수요의 성격    그런데 공고의 90.8%는 대졸을 찾지 않는다        ← 3단계
③  어긋남        계열별로 어긋나는 모양이 다르다                ← 1단계에서 살아남은 부분
④  업종·지역     대졸을 찾는 자리는 업종·지역에 몰려 있다
⑤  결과          남으면 월 37.7만원을 덜 받는다                 ← 4단계 (+ 2단계 귀무 결과)
⑥  반론 검증     덜 받아도 주거비가 싸면 상쇄되나 → 안 된다      ← 5단계
⑦  선행연구 대조  이미 알려진 것과 우리가 더한 것                ← 6단계
⑧  품질 점검     표본·이상치·관계를 흔들어본 결과                ← 7단계
제안             「더 키우기」가 아니라 「첫 1년 버티기」
```

# 팀원이 알아야 할 규칙 3가지

1. **데이터를 합칠 때는 직업 이름이 아니라 6자리 직업코드로 붙인다.**
   문서마다 13개 큰 분류의 이름 체계가 다르다 —
   어떤 문서는 13번이 「정보통신」, 다른 문서는 13번이 「농림어업」이다.

2. **개수를 비교하지 않는다.** 졸업생은 1년 동안 나온 수, 공고는 하루 기준 모집 중이던 수다.
   기간이 다르므로 **비율(%)과 비율 차이(%p)로만** 말한다. 「몇 배」는 금지다.

3. **새 숫자는 `숫자표_검증완료.md`에 먼저 올리고 쓴다.**
   특히 「대졸요구율」은 우리 파일에 **두 종류**가 들어 있다(전체 기준 9.2% / 학력 명시 기준 28.6%).
   섞이면 심사에서 바로 걸린다.
