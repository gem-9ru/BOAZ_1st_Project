### A-7. 「부산은 주거비가 싸잖아」에 대한 답

**세 겹으로 걸러야 비교가 성립한다** — ① 부모집 거주자 제외 ② 보증금 있는 월세만
③ 이상치 제외(월세 100만원 초과). 걸러내는 정도에 따라 답이 달라지므로 기준을 반드시 밝힌다.

| 거른 정도 | 부산 | 수도권 | 차이 | 쓸 수 있나 |
|---|---|---|---|---|
| 전체 | 41.1 | 35.0 | −6.1 | ✗ 부모집 거주자(부산 22.3%)가 부풀린다 |
| + 자취·분가만 | 34.9 | 37.5 | +2.6 | ✗ 수도권 전세 42.4%라 수도권이 과소평가 |
| + 보증금 월세만 | 43.0 | 43.5 | +0.5 | ✗ 부산에 월 732만원 같은 오기가 섞임 |
| **+ 이상치 제외** | **37.7**<br>(n=212) | **43.5**<br>(n=124) | **+5.8** | **✓ 이것만 쓴다** |

| 항목 | 값 |
|---|---|
| 이 표본의 월소득 | 부산 203.1 · 수도권 243.4 → 명목 격차 **+40.3** |
| 월세가 메워주는 몫 | **5.8만원 = 격차의 14%** |
| 남는 격차 | **34.5만원 (86%)** · 중앙값 기준 32만원 (80%) |
| 소득 대비 월세 비중 | 부산 **18.6%** > 수도권 17.9% (월세는 싼데 소득이 더 작다) |

> **월세 분포** — 중앙값 40만원, 상위 25%가 50만원, 70만원 이상은 4.9%다.
> 2018·2019년 졸업생이 대상이라 **2020~2022년 무렵의 가격**이다.

### A-7b. 고용24 시도별 요구학력 — 비교의 한계를 보여주는 표

발표에서 "다른 지역은요?"라는 질문이 나오면 **이 표를 먼저 꺼낸다.**

| 시도 | 구인공고 | 대졸 이상 요구 | 학력 무관 |
|---|---|---|---|
| 대전 | 29,205 | 5.0% | 85.5% |
| **부산** | **130,247** | **1.0%** | 93.8% |
| 전국 | 1,943,883 | 0.8% | 92.2% |
| **서울** | 310,586 | **0.8%** | 93.3% |
| 경기도 | 520,234 | 0.4% | 92.8% |

부산은 20개 시도 중 **9위로 낮지 않다.** 그래서 **「부산이 유독 대졸을 안 찾는다」고 말하지 않는다.**
공공 채널(고용24)은 학력 무관이 92%라 애초에 학력을 잘 기록하지 않는다 —
우리 크롤링(학력 무관 59.7%)과 **채널이 달라 수준 비교도 못 한다.**

> **그래서 주제를 「엇갈린 결」로 되돌렸다.** 이건 **부산 안의 두 가지**
> (부산 대학이 내보내는 것 ↔ 부산 일자리가 찾는 것)를 비교하는 말이라
> 타지역 비교 없이 성립한다.

## B. 쓰면 안 되는 숫자

| 쓰지 말 것 | 왜 |
|---|---|
| 「필요 인원의 **3.41배**를 배출」 | 기준을 바꿔 114가지로 재보니 **0.84~3.95배**. 방향까지 뒤집힌다 |
| 「부산 일자리의 **67.5%**」 | 정부 채용 사이트 기준 값. 민간 공고 기준으로는 32.4% |
| 「떠난 비율과 자리 여유의 관계 **+0.68**」 | 계열을 묶는 방식 4가지 중 **가장 유리한 하나**였다.<br>그것도 **우연일 확률이 9.4%**라 인정 기준(5%)을 넘는다.<br>나머지 세 개는 +0.23~+0.31, 우연일 확률 46~50%.<br>→ **「자리의 개수로는 설명이 안 된다」까지만** 말한다 |
| 「25-29세 순유출률 **전국 1위**」 | 광주 18.54 > 부산 16.05. **2위** |
| 「20년 누적 18만6천명 = 졸업생의 **5배**」 | 20년치와 1년치를 나눈 값이다. 기간이 달라 비교가 안 된다 |
| 「7개 계열 **전부** 임금이 높다」 | 사람마다 다른 조건을 맞춰 비교하면 일부 계열만 차이가 확인된다 |
| 공고에 적힌 **연봉 중앙값** | 공고의 **59.0%가 급여를 안 밝힌다**(「면접 후 결정」 8,609건). 대표성 없음 |
| 업종 **순위** 주장 | 업종을 모르는 공고가 31.6% |
| 「**대졸이 갈 자리가 3.2%**」 | 요구 학력은 대개 하한선이다. 학력무관·전문대·고졸 공고에도 대졸은 지원할 수 있다.<br>**대졸이 지원 가능한 자리는 94%다.**<br>→ 「기업이 **대졸이라는 점에 값을 매기는** 자리가 3.2%」라고만 쓴다 |
| 「대졸을 부르는 업종일수록 **불안정하다**」 | 업종 10개로 재보면 **관계가 확인되지 않는다**<br>r=−0.23(t=−0.67) · 순위 기준 +0.08 · 공고수 가중 −0.40<br>**교육을 빼면 부호가 뒤집힌다(+0.30).** 교육 한 업종이 만든 모양이다 |
| 「주거비 차이가 **0.5만원**뿐」 | 부산 쪽에 **월 732만원 같은 오기**가 섞여 평균이 43.0으로 부풀려진 값이다.<br>이상치를 빼면 부산 37.7, **차이 5.8만원**이다 |
| 「부산은 **다른 지역보다** 대졸을 안 찾는다」 | 우리 크롤링은 **부산만** 모아 타지역 비교가 불가능하다.<br>비교 가능한 유일한 자료(고용24 12개월)로는<br>**부산 1.0% > 서울 0.8% = 전국 0.8%**, 20개 시도 중 9위 — **부산이 낮지 않다**<br>→ 어긋남은 **부산 안의 배출 vs 수요**로만 말한다 |

## C. 숫자를 쓰기 전 통과해야 할 3가지 (`build/quality.py`)

| 검사 | 기준 | 통과 못 하면 |
|---|---|---|
| **표본 수** | 비율은 n ≥ 100 | 30~99는 별표(*)와 흐리게 · 30 미만은 표시 금지 |
| **이상치** | 처리 방식을 바꿔도 결론이 유지되는가 | 바뀌면 그 숫자를 헤드라인에 쓰지 않는다 |
| **관계 주장** | 점을 하나씩 빼도 부호가 유지되는가 | 뒤집히면 **쓰지 않는다** |

현재 상태 — **표본 경고 2건**(건설·채굴 76건, 농림어업 62건),
**임금 격차는 6가지 처리 전부 36.7~37.7만원으로 견고**,
**관계 주장 4개는 전부 사용 불가**(그래서 하나도 쓰지 않는다).

## D. 캡션에 반드시 들어갈 한계 3줄

```

  업종 구성은 비교용이며 순위는 주장하지 않는다.
· 주거비는 거주 형태를 고정해 비교했다(혼자 살거나 분가한 사람만).
  주거비 항목이 있는 2018·2019년 졸업생만 대상이다.

```
